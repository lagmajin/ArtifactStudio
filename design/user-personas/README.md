# ArtifactStudio User Personas

**最終更新:** 2026-08-13

ArtifactStudio の機能、UI、AI連携、テキストアニメーションを評価するためのユーザーペルソナ資産。

## 使い方

機能案を評価するときは、少なくとも「モーションデザイナー」と「必要に迫られて使う人」を通し、入力負荷がある操作ではアクセシビリティ制約プロファイルも確認する。初心者向けの導線を追加する場合は、操作の発見性と失敗からの復帰を確認する。

ペルソナは人物を決めつけるためではなく、異なる目的・経験・制約を設計に持ち込むために使う。

## 収録資産

- [motion-designer.md](motion-designer.md): 表現品質と再利用性を重視する専門制作者
- [reluctant-operator.md](reluctant-operator.md): 本来の目的のために必要最低限の制作を行う人
- [beginner.md](beginner.md): 用語やアニメーション設計に不慣れな人
- [accessibility-operator.md](accessibility-operator.md): 入力・視認・疲労などの制約を持つ制作者
- [api-agent.md](api-agent.md): 初めてのアプリをAPI経由で理解・実装するAIエージェント
- [evaluation-matrix.md](evaluation-matrix.md): 機能を横断して評価する共通基準
