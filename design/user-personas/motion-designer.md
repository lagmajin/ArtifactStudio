# モーションデザイナー

**最終更新:** 2026-08-13

## 状況

映像、広告、配信、タイトルアニメーションを継続的に制作する。AE等の経験があり、用語や階層構造は理解しているが、反復設定と微調整に時間を奪われている。

## 成功条件

- 意図した動きを短時間で作り、後から正確に再調整できる
- 文字単位・単語単位・行単位・意味単位を切り替えられる
- 絵文字、合字、改行、多言語でも見た目と選択範囲が破綻しない
- プリセットを適用しても、重要なパラメータを失わない

## 嫌う作業

- 同じ設定を文字ごとに繰り返すこと
- タイムライン上の小さなキーフレームを探して修正すること
- 何が選択されているか分からない状態での調整
- AEの挙動を覚えるためだけの回避操作

## 設計要求

`左から順に回転`、`単語ごとに跳ねる` のような意図を直接指定できること。selector order、stagger、anchor、easing を独立して編集でき、同時にプレビューできること。

## テキストアニメーションの可能性マップ

新しい機能を検討するときは、次の軸の組み合わせを確認する。軸を一つの巨大な「Animator」設定に詰め込まず、独立した意味として編集・保存・AI指定できることを重視する。

### 1. 何を選ぶか

- 文字、書記素クラスタ、絵文字、合字、単語、行、段落、タグ、正規表現範囲
- 左右、右左、中央から外、外から中央、ランダム、読み順、カスタム順序
- 文字の出現順、視覚上の位置、言語の読み方向を別々に扱う
- 固定範囲、追従範囲、ランダム範囲、意味タグ範囲

### 2. 何を変えるか

- 位置、回転、スケール、傾き、奥行き、アンカー、ベースライン
- 不透明度、塗り、線、太さ、ぼかし、グロー、マスク、クリップ
- 字間、行間、文字幅、ウェイト、斜体、可変フォント軸
- 形状、輪郭、塗りのワイプ、グリフの置換、出現・消失、分割・結合
- 3D回転、カメラ向き、ビルボード、文字ごとの深度と遮蔽

### 3. どう動かすか

- 一括補間、文字ごとの遅延、波、パルス、ループ、往復、ホールド
- イーズ、ばね、慣性、オーバーシュート、減衰、量子化、ステップ
- ノイズ、揺らぎ、ランダムシード、相関、位相、周波数、振幅
- 音声・音量・ビート・マーカー・外部データへの反応
- 物理風の衝突、落下、跳ね、群れ、流体、吸着、ばらし、再集合

### 4. どの空間で動かすか

- ローカル文字座標、単語座標、行座標、レイヤー座標、コンポジション座標
- ベースライン、ボックス、パス、円、螺旋、グリッド、自由曲線
- パスに沿う、パスから離れる、形状へ整列、領域を埋める、回避する
- 2D、2.5D、3D、カメラ相対、スクリーン相対

### 5. いつ動かすか

- 開始・終了、範囲、オフセット、ステップ、スタッガー、反転
- 文字ごと・単語ごと・行ごとの時間単位
- クリップイン・アウト、マーカー、ビート、ワークエリアへの追従
- リタイム、速度グラフ、ループ、ランダム開始、途中状態からの再開

### 6. どのように重ねるか

- 複数Animatorの加算、置換、乗算、最大・最小、ブレンド
- 選択範囲の合成、親子関係、プリセットの継承と部分上書き
- 変形順序、アンカー順序、色とジオメトリの独立性
- 非破壊編集、差分表示、パラメータの由来と優先順位

### 7. 文字構造が変わる場合

- テキスト編集・差し替え・フォント変更・サイズ変更後の安定性
- 改行、空白、句読点、RTL、縦書き、CJK、合字、結合文字、絵文字
- オーバーフロー、折返し、欠落グリフ、フォールバックフォント
- 文字数が増減したときの時間・範囲・物理状態の再計算

## 発想を漏らさないための代表シナリオ

少なくとも次のシナリオを、静的シミュレーションと実動作テストの両方で確認する。

| シナリオ | 代表的な組み合わせ |
|---|---|
| タイトル登場 | 左から、回転、スケール、ばね、文字ごとの遅延 |
| 単語の強調 | 単語選択、色、スケール、パルス、ホールド |
| タイプオン | 書記素単位、クリップ、カーソル、速度一定、改行 |
| 文章の入替 | 旧文の退場と新文の登場、差し替え、再利用可能なIntent |
| ロゴ・見出し | パス追従、字間、3D回転、カメラ、奥行き |
| 音楽同期 | ビート、振幅、ランダムシード、減衰、ループ |
| 物理的分解 | 文字単位、衝突、重力、ばらし、再集合 |
| データ表示 | 数値差し替え、桁増減、単位、整列、色の閾値 |
| 多言語表示 | RTL、CJK、絵文字、合字、行分割、読み順 |
| AI生成 | 自然言語Intent、プレビュー、差分、修正、再実行 |

## AE模倣時に意識する改善点

- 数値の意味が文脈依存にならないよう、対象・単位・範囲を表示する。
- 選択順、時間順、描画順、読み順を一つの「順序」に混ぜない。
- Animatorの重ね順と変形のピボットを、結果だけでなく構造として確認できるようにする。
- 文字列変更時に黙って壊すのではなく、範囲・時間・物理状態の再計算結果を提示する。
- 特殊文字を例外扱いせず、最初から書記素クラスタと行レイアウトを基準にする。
- 高度な表現を追加する前に、プレビュー、再現性、Undo、診断、AI指定を揃える。

## モーションデザイナーが期待するプリミティブ

最低限、`selection`、`order`、`unit`、`property`、`from/to`、`timing`、`easing`、`anchor`、`space`、`blend`、`seed`、`preview`、`verify` を別々に指定できるIntentを期待する。これらを組み合わせて新しい表現を作れることが、個別プリセットを増やすより重要である。

## 失敗判定

見た目が一度出ても、再編集時に順序・範囲・ピボット・時間差の関係が読めなければ失敗とみなす。

次の場合も失敗とみなす。

- 軸の組み合わせで、どの設定が原因か追跡できない
- 文字列変更で選択・時間・レイアウトの整合性が失われる
- できる表現がプリセットに閉じ、Intentとして再構成できない
- 高品質な見た目のために、長い待ち時間や細かい手作業を要求する
