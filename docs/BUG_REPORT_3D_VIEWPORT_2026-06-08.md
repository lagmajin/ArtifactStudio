## BUG 1: Matrix Transpose Mismatch (Critical)

**Files**: `ArtifactDiligentEngineRenderWindow.cpp` (upload) / HLSL shader (inline)

**Symptom**: All matrices (world, view, proj) are effectively transposed in the shader, producing incorrect rotation direction and broken projection.

**Root Cause**:
- `QMatrix4x4` stores data in column-major order (OpenGL convention)
- HLSL default constant buffer packing is column-major
- Shader uses `mul(v, M)` (row-vector × matrix)
- With column-major packing, `mul(v, M)` reads columns as rows → effectively `v * M^T`

**Consequence**:
- Rotations inverted (25° becomes -25°)
- Translation/rotation ordering swapped
- Perspective projection mathematically incorrect

**Fix options**:
1. Transpose each matrix before `memcpy` into the cbuffer
2. Change shader to `mul(M, v)` and add `#pragma pack_matrix(row_major)`
3. Change shader to `mul(WorldMatrix, float4(input.position, 1.0f))` and upload QMatrix4x4 data as-is

## BUG 2: Zoom Constant Mismatch (Minor)

**Files**: `Artifact3DModelViewer.cppm:162` vs `ArtifactDiligentEngineRenderWindow.cpp:329`

**Symptom**: Preview distance is always 80% of orbit distance, making zoom feel inconsistent.

**Root Cause**: Viewer computes `zoomFactor = 5.0f / orbitDistance_`, render window computes `previewDistance_ = 4.0f / previewZoom_`. Chain: `previewDistance_ = 0.8 * orbitDistance_`.

**Fix**: Change one constant to match — either `5.0f`→`4.0f` in viewer or `4.0f`→`5.0f` in render window.

---

## BUG 3: Vertex Attributes Discarded on Upload (Medium)

**File**: `ArtifactDiligentEngineRenderWindow.cpp` (`uploadMeshGeometry`, line 462-504)

**Symptom**: Normals, UVs, and index data are generated by `generateRenderData()` but only positions are uploaded to GPU. The input layout declares only `ATTRIB0 (float3 position)`.

**Impact**: No lighting possible. CPU work wasted on normal/UV generation.

**Fix**: Expand vertex buffer to include normals (and optionally UVs), update input layout, extend the simple solid-color shader or add a new PSO with proper vertex format.

## BUG 4: Default Camera Values Are Dead Code (Trivial)

**File**: `ArtifactDiligentEngineRenderWindow.ixx:65-68`

**Symptom**: `previewYaw_ = 35°`, `previewPitch_ = 25°` defaults are immediately overwritten by `Artifact3DModelViewer::resetView()`.

**Fix**: Remove or reset the defaults to 0.

---

## BUG 5: Pan Does Not Account for Camera Rotation (Minor)

**File**: `Artifact3DModelViewer.cppm` (eventFilter, pan handler)

**Symptom**: Pan moves target in pure XY world space regardless of current yaw/pitch, so panning right when the camera is rotated 90° does not move right on screen.

**Fix**: Transform the pan delta by the inverse of the current yaw/pitch rotation to move in camera-relative screen space.
