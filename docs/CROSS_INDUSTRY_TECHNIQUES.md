# 他業界・異分野技法参照

> ArtifactStudio に応用可能な、VFX/コンポジット業界以外の技法・アイデア集
> 印刷、生物学、建築、地図学、天文学、医療、音響、錯視心理学など

---

## 印刷・出版

| 技法 | 概要 | ArtifactStudio 応用 |
|---|---|---|
| AM/FM 網点 (Halftone) | ドットのサイズ(AM)・密度(FM)で濃淡を表現する古典的印刷技法 | 画像→網点変換エフェクト。新聞・漫画風 |
| 色分解 + スクリーン角度 | CMYK 4版を異なる角度で重ねる。角度ずれでロゼッタパターン発生 | ポスタリゼーション＋角度付き網点合成 |
| トラッピング (Trapping) | 版境界をわずかに重ねて紙の伸縮による白ズレを防ぐ | レイヤー境界の自動補完・アンチギャップ |
| ダブルトーン / トリトーン | 2〜3色のインクで階調表現。写真を劇的に印象付ける | モノクロ→多色変換フィルタ |
| ドットゲイン | 紙へのインク浸透で網点が太る現象 | ソフトなエッジ太り・境界ぼかし |

## 生物学

| 技法 | 概要 | ArtifactStudio 応用 |
|---|---|---|
| 反応拡散 (Turing Pattern) | 2化学物質の拡散と反応で縞・斑点が自己組織化。Gray-Scottモデル | 毛皮模様・葉脈・指紋・迷彩 |
| フィロタキシス | 黄金角 137.5° で葉・種を配置する植物の法則 | ひまわり・松ぼっくりパターン |
| L-system | 文法規則の再帰で植物の枝分かれを生成 | フラクタル植物・稲妻・血管分岐 |
| 差分成長 (Differential Growth) | 細胞が不均等に分裂しながら形を形成 | 有機的形状・腸・脳シワのアニメ |
| 群体行動 (Flocking/Boids) | 3ルール（分離・整列・結合）で群れが創発 | パーティクルの自然な群れ制御 |
| 粘菌ネットワーク (Slime Mold) | 粘菌が餌を結ぶ最短経路網を自己形成 | テキスト/ロゴ間の有機的接続アニメ |
| 葉脈パターン | オーキシン濃度勾配で形成される分岐網 | 川・血管・根のパターン生成 |

| 図法投影 | 球面→平面の多様な変換 (Mercator, Mollweide 他) | テクスチャの極座標歪曲・魚眼 |

## 錯視・知覚心理学

| 技法 | 概要 | ArtifactStudio 応用 |
|---|---|---|
| モアレ縞 | 2つの周期パターンが干渉して生じる低周波模様 | レイヤー合成の干渉縞エフェクト |
| マッハバンド | 輝度段差の境界で錯覚的な強調が起こる | 疑似ハイライト・シャドウ |
| 運動残効 (MAE) | 一方向の運動に順応後、静止画が逆方向に動いて見える | 錯視ベースのトランジション |
| ストロボ効果 | 周期的な遮断で運動が静止/逆転して見える | コマ撮り風・ストップモーション |

## アルゴリズムアート

| 技法 | 参照 | 概要 |
|---|---|---|
| ストレンジアトラクタ | Lorenz, Rössler, Clifford | カオス方程式の軌道で複雑な粒子モーション |
| フラクタルフレーム | Scott Draves 1992 (Electric Sheep) | 反復関数系 (IFS) で炎・雲・シダ |
| ドメインワーピング | Inigo Quilez | ノイズ関数の入力座標を別のノイズで歪める高度な模様 |
| ピクセルソーティング | Kim Asendorf | 輝度/色相に沿ってピクセル列をソートするグリッチ |
| スリットスキャン | 映画 2001年宇宙の旅 | 1行ずつ時間差キャプチャで時間を空間化 |
| ドロステ効果 | エッシャー「版画の画廊」 | 画像内に自分自身を無限再帰的に含める |
| データモッシング | 動画のIフレーム削除+Pフレーム連続 | 映像が溶けて流れるグリッチ |
