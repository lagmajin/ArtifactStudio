# モーショングラフィック制作アプリの思考メモ

日付: 2026-05-28

このメモは仕様書ではなく、AE っぽい制作アプリを「広告動画の量産に強いツール」として考えるための整理メモ。

## まずの前提

- ユーザーは 1 本の完成度を上げるより、同じ構成を速く大量に回したいことが多い
- 価値の中心は「表現力」だけではなく、「面倒な反復作業の圧縮」にある
- したがって、編集の自由度と同じくらい、差し替え・再利用・安全確認が重要になる

## 面倒なタスクの候補

1. テキスト差し替え
   - 商品名、価格、日付、CTA、店舗名、キャンペーン文言
2. 尺合わせ
   - 6 秒、15 秒、30 秒への再構成
3. サイズ展開
   - 16:9、1:1、9:16、4:5 の一括出力
4. ブランド統一
   - 色、フォント、ロゴ位置、余白ルールの維持
5. 素材入れ替え
   - 商品画像、人物写真、背景、動画クリップの差し替え
6. アニメーション再利用
   - 文字出現、強調、価格ポップ、アイコン演出のテンプレ化
7. 自動 QA
   - はみ出し、重なり、文字切れ、コントラスト不足の検出

## どこに時短価値が出るか

- いちばん効くのは、毎回発生する「差し替え」と「再出力」
- その次に効くのが「サイズ違いへの展開」
- その次が「文量の違いに対する自動レイアウト」
- 最後に「安全チェック」を入れると、量産時の事故を減らせる

## 重要そうな利用者

1. 広告運用者
   - バリエーションを大量に回したい
2. EC 担当
   - 商品情報の更新に追従したい
3. SNS 運用者
   - 縦動画を定期的に量産したい
4. デザイナー / 動画制作者
   - テンプレを作って案件を高速にさばきたい

最初の狙い目は、広告運用者と EC 担当寄り。

## 仕組みとして強い方向

- テンプレートを 1 回作る
- 差し込み項目を定義する
- CSV / JSON / フォームから複数案件を流し込む
- レイアウトを文量に応じて自動調整する
- 画角別に自動生成する
- はみ出しだけ検出して警告する

この流れがあると、手作業で 1 本ずつ直す作業が「量産フロー」に変わる。

## 機能の優先順メモ

1. テキスト差し替え
2. サイズ展開
3. 自動レイアウト
4. 安全チェック
5. テンプレ保存と再利用
6. CSV 一括生成
7. バリエーション出力
8. 尺自動調整
9. ブランドルール管理

## ひとことで言うなら

- 動画編集ソフトというより、動画の量産機
- AE 代替というより、広告動画の自動組み立てツール
- 表現ツールというより、反復作業を消すツール

## MVP の芯

- 1 つの広告テンプレを作る
- 差し替え項目を定義する
- CSV で複数案件を流し込む
- 縦横サイズを自動生成する
- はみ出しだけ警告する

このくらいでも、実務上の時短価値はかなり出るはず。
