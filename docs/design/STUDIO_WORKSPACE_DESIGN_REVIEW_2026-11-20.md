# ArtifactStudio ワークスペース再設計案

**最終更新:** 2026-11-20

新規作成から編集まで、次の操作と現在の作業対象がひと目で分かる画面にする。主役は中央の Composition Viewer と下段の Timeline。Project は素材を探す場所、右ドックは選択した対象の詳細を編集する場所として配置する。

## 実機で見えたこと

証跡はローカルの `captures/studio-design-2026-11-20/` に保存した。2026-11-20 の既存 Debug 実行ファイルを、日本語表示のプロジェクト未オープン状態で観察した。

1. **起動直後**（`01-workspace.jpg`）。Project が横幅の約45%、Composition Viewer が約33%を占める。中央の「新規コンポジション」は見つけやすい。一方、左にも空状態の案内があり、広い検索欄と項目のない一覧が Viewer より目立つ。右ドックは `Inspec…`、`Compone…`、`Propert…` と同時に省略され、切り替え先を判断しづらい。メニューバー上端はキャプチャで欠けている。
2. **編集メニュー**（`02-edit.jpg`）。区切り線とショートカット列で操作を探せる。分割・イン／アウトのトリムはアイコンの面積が小さく、無効時に輪郭の差が消える。アンバーの選択行では白いラベルとの明暗差が小さく見える。正確なコントラストとキーボードフォーカスは要確認。
3. **選択サブメニュー**（`03-selection.jpg`）。すべて選択・選択反転・同種選択が小さな四角形に見える。状態色が失われても判別できる輪郭が必要。

## 提案する画面構成

| 面 | デザイン案 | 確認すること |
| --- | --- | --- |
| ワークスペース | 既定レイアウトの横幅比を Project 22%、Viewer 56%、右ドック 22%から検討する。保存済みレイアウトを尊重し、ウィンドウが狭いときは左右ドックの内容に応じて優先順位を付ける。 | 素材名・ドック名が読め、Viewer に作業面積を確保できる。 |
| 空状態 | Viewer の新規コンポジションを主操作に据える。Project の案内から既存のプロジェクトを開く入口へ迷わず進める構成を検討する。 | 起動直後に「始める」「開く」が見つかる。 |
| Viewer 周辺 | ドック名と編集中のコンポジション名を異なる階層で表示。上部に編集ツール、下部に倍率・表示品質・再生、最下段に解像度と fps をまとめる。 | 同じ情報が二重に表示されず、主要操作が最短の視線移動で見つかる。 |
| 右ドック | アクティブなタブ名を全文読める幅を優先し、狭いときは既存のドックメニューで他パネルへ移動できるか確認する。プロパティは選択対象と主要項目から読める順序にする。 | Inspector、Components、Effects、Property を見分けられる。 |
| Timeline とステータス | Timeline の時刻・再生ヘッド・行選択を主情報とする。アプリ最下段はプロジェクト状態やバックグラウンド処理など全体に関わる情報を優先し、Viewer 固有の情報は Viewer 側で確認できる構成を検討する。 | 編集中にも作品、時刻、選択レイヤーの対応を追える。Timeline は今回未観察のため仮説。 |
| 配色とメニュー | 背景はニュートラルなチャコールを基調に、操作面は明度差で区切る。キーボードフォーカスは線、選択は面、警告は意味色で伝える。アイコン列・ラベル列・ショートカット列を揃え、明暗差は通常・選択・無効状態で確認する。 | 現在位置と操作可否を色以外でも判断できる。 |

Viewport の提案範囲は描画領域外のタブ、ツールバー、表示／再生コントロール、ステータス行。採用範囲は [Composition Viewport の仕様](composition-viewport/README.md) に従う。

## アイコンの変更

編集メニューの分割、イン／アウトのトリム、すべて選択、選択解除、選択反転、同種選択の SVG を差し替えた。片側に残すブロックと切断位置、選択枠の内側の記号、白黒の反転面など、色を落としても形に差が残るようにした。すべて選択など一部の SVG は Timeline のコンテキストメニューでも共有される。`04-edit-icons.png` は Qt SVG で16pxに描画した比較で、各列の右側はその2倍拡大。

## 確認範囲

実機キャプチャは日本語の起動直後と編集メニュー。レイヤー選択時の Viewer、Timeline、右ドック、他のメニュー、差し替え後の実機表示、言語マトリクスは未確認。総合案の優先順位は、起動時の面積配分とタブの可読性、メニューの状態別コントラスト、編集状態の情報配置の順とする。
