# Add Effect ダイアログ採用デザイン

**最終更新:** 2026-09-07

承認済み参考画像: [approved-add-effect-dialog-2026-09-07.png](approved-add-effect-dialog-2026-09-07.png)

## 採用方針

- Effectsラックと同じチャコール基調、青い選択アクセント、Studioエフェクトアイコンを使う。
- 対象レイヤー／コンポジションと処理ステージを上部で識別できるようにする。
- 検索を主要導線とし、左にカテゴリ、中央に説明付きエフェクト一覧、右に選択詳細を配置する。
- ダブルクリック追加と Add Effect ボタンの既存操作を維持する。
- カテゴリ、説明、件数は既存 `EffectCatalogEntry` を表示元とし、架空の登録情報を持たせない。

## 実装（2026-09-07）

- モック画像をリポジトリのデザイン参照として保存。
- 動的カテゴリ一覧と件数、カテゴリ絞り込みを追加。
- エフェクト行をアイコン、名称、説明、カテゴリ、追加 affordance の構成へ変更。
- 選択エフェクトの名称、説明、カテゴリを右側の詳細ペインへ表示。
- 対象とステージをコンテキストヘッダーへ整理し、下部の説明と主要アクションを分離。

既存の検索、選択、ダブルクリック、確定／取消経路を再利用する。QtCSSと新規シグナル接続は追加していない。ユーザー指示によりビルド・テスト・実画面検証は未実施。
