## 採用範囲

この画像は `ArtifactAICloudWidget` 単体の情報設計、配置、密度、配色の参照とする。

- 上部にウィジェット名、モデル選択、接続状態、詳細表示、設定導線を集約する。
- 会話を主領域とし、入力欄を下端にコンパクトに配置する。
- Connection / Tools / MCP は補助ペインにまとめ、既定では非表示とする。
- 既存の provider、tool approval、Tool Bridge、MCP transport、送信／キャンセル経路は維持する。

画像内の具体的な解析結果、件数、時刻、アイコン形状は例示であり、実装要件には含めない。画像を理由に新しい AI 機能やツール実行経路を追加しない。
