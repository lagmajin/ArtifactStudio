# Collaboration Presence Widget concept

**最終更新:** 2026-09-10

`collab-presence-widget-concept-2026-09-10.png` は `CollabPresenceWidget` の情報階層、配置、密度、配色の採用モックである。

## 採用範囲

- ローカルユーザーと参加者を、識別色、名前、現在位置、選択レイヤー数で表示する。
- ローカルユーザーを `You` として区別する。
- 狭いドックでも読みやすい縦型リストにする。

画像内の接続状態、ユーザー名、位置、レイヤー数は例示である。招待、権限、チャット、コメント、競合解決、ロック操作はこのモックの採用範囲に含めない。
