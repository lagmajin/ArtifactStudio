# Color picker reference

**最終更新:** 2026-09-07

承認済み参考画像: [approved-color-picker-2026-09-07.png](approved-color-picker-2026-09-07.png)

## 実装

Artifact の FloatColorPickerHooks で既存 FloatColorPicker を再配置。ArtifactWidgets は変更せず、既存の色変換・入力・ドラッグ・通知経路を再利用する。

- RGB / HSL タブ、24px のチャンネルグラデーション、細い位置マーカー、数値入力、HEX。
- 作成用: 作成色と「この色を使う」。コンポジション・平面・グラデーション作成のドラフトだけを更新し、オブジェクト生成は外側の作成ダイアログが担当。
- 既存編集用: 変更前／変更後の比較と「変更を確定」。変更前のスウォッチで元の色を呼び戻せる。ドキュメントへの確定・取消は呼び出し元が担当。
- 直近12色をアプリ設定に float RGBA として保存。キャンセルした色は保存しない。履歴選択は既存プレビュー通知経路を通す。
- プロパティ編集、コンポジション背景設定、ブラシ色、アプリ設定、パレット生成にも適用。
- コンポジション設定内のピッカー取消は、そのピッカーを開いた時点の色へ戻す。

## 参考画像との差・確認待ち

色空間切替、8-bit 表示切替、スポイト、プロジェクトパレット、ライブプレビュー切替は未実装。RGB / Alpha は既存の 0–1 入力を維持。グラデーションは UI 表示用で、シーンのカラーマネジメントや HDR 対応を追加するものではない。履歴は作成対象の生成成功ではなく、色ダイアログでの確定を記録する。

既存の一部専用カラーエディタおよび ArtifactWidgets 内部から直接開くピッカーは対象外。起動中の色の監視には表示中だけ動作するローカルタイマーを使用する。QtCSS・新規シグナル接続は追加しない。

ユーザー指示によりビルド・テストは未実行。実画面での表示、ドラッグ、数値・HEX編集、履歴、キャンセルの検証は未実施。

## HSV / Lab / XYZ — 2026-09-07

ユーザー指定によりHSV・Lab・XYZを追加。HSVは既存HSBページを再利用し、ValueをVと表示する。Lab / XYZは既存Core変換を利用する数値入力タブ。

- Lab: CIELAB、D65白色点、L* 0–100、a*/b* −128–127。
- XYZ: D65、Y=1基準、各値 0–2。
- 既存変換はsRGB符号値を前提とする。作業色空間の自動切替やICC対応ではない。
- 数値のEnter・フォーカス移動・スピン操作で色を反映。タブ切替だけでは色を変更しない。
- アルファは保持。RGB域外は既存Core変換でクリップし、変換後の値を表示する。
- Lab / XYZの専用グラデーションスライダーは未追加。RGB / HSL / HSVのスライダーと共通履歴は引き続き利用できる。

QtCSS・新規シグナル接続・Core / ArtifactWidgets変更なし。ビルド・テスト・実画面検証は未実施。
