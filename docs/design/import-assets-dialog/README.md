# Import Assets dialog design reference

**最終更新:** 2026-09-09

Version 2 は実装参照として採用し、Version 1 と Version 3 は比較用に残す。

- `import-assets-dialog-concept-2026-09-09.png`: Version 1。現行項目のみの基準案。
- `import-assets-dialog-v2-details-2026-09-09.png`: Version 2・採用。合計件数／容量、コピー先、代表ファイル、連番範囲、同名警告、取り込み候補の集計を加えた案。
- `import-assets-dialog-v3-polished-2026-09-09.png`: Version 3・比較案。Version 2 と同じ情報を、より広いテーブルと強い要約カードで表現したもの。

参照対象は、現行 `ArtifactImportAssetsDialog` の説明、Group／Items表、グループ単位のチェック、Project/Assetsへのコピー導線の配置・密度・配色に限定する。画像内の件数はレイアウト例である。サムネイル、競合設定、保存先選択などの新機能追加根拠にはしない。

Version 2 の追加情報は既存の入力ファイル一覧からダイアログ構築時に一度だけ集計し、プレビュー画像生成やファイル内容のデコードを要求しない。

Version 3 の広い要約・テーブル密度・主要操作の視覚階層を現行ウィジェットへ追加反映した。集計内容、グループチェック、選択パス、既存の確定／取消接続は変更していない。
