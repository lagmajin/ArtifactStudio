# Solid creation dialog

**最終更新:** 2026-09-07

[承認済み画像](approved-solid-create-2026-09-07.png)

サイズ・カラー・配置の項目と既存操作を維持して整列。数値はアンバー、作成ボタンは青。入力欄は32px以上、幅・高さは同幅にし、リンクボタンを入力欄の近くへ配置。空の作成見出しを削除し、配置見出しを追加。サイズ適用ボタンの横幅とプリセット間隔を調整。

局所QProxyStyleとQPaletteを使用。リンク状態は絵文字ではなく描画で表示。既存接続・カラー選択経路は再利用。共通レイアウト部品の調整は平面設定の編集側にも反映されるが、作成側だけ確定ボタンを「作成」と表示する。

元の画像を保持したうえで保存。差分の空白確認のみ実施。ビルド・テスト・実画面確認は未実施。追加のグラデーション項目は既存スクロール領域で表示する。
