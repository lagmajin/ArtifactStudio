既存のタイムライン案を基に、グラフ部分だけ FabFilter の視認性と色の重なりを控えめに取り入れた画像生成モック。

- 曲線の下に薄い半透明の塗りを追加。
- 曲線を鮮明にし、グリッドは控えめにする。
- 選択キーは白い輪郭とアンバーの中心で強調。
- 左ペイン・ツールバー・キー編集欄の構成は元の案を維持。

2026-09-07 の承認・保存対象はデザイン参考画像。実装は当時の保存作業に含まない。

## 2026-10-09 レイアウト反映

ユーザーのスクリーンショット指摘と実装依頼に基づき、既存の編集機能を使って参考画像へ近づけた。

- カーブモードの初期左右比率は約26:74。通常タイムラインとカーブで変更した左幅をそれぞれ保持する（ウィジェットの生存期間内）。
- カーブツールバーと高さ40のナビゲーターを全幅へ配置。カーブ自身の時間軸を使い、通常タイムラインのRAM cache／work area行はカーブモードで非表示とする。
- 左ペインはチャンネル色のスウォッチ、チャンネル名、レイヤー名を表示し、選択行を青で強調する。空状態にはアニメーション付きレイヤーの選択案内を表示する。
- グラフは縦方向にも拡張。下部のFrame／Value操作は未選択時にも無効状態で表示し、単一キー選択時には現在のフレーム／値を表示する。

完全一致ではない。チャンネル一覧はフラットなリスト、Frame／Value編集は既存ダイアログ経由、共通タイムラインヘッダーは継続使用する。ビルド・実機の表示確認は未実施。
