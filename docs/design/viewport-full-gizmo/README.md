# Compact Full Gizmo

**最終更新:** 2026-09-07

[承認済みデザイン](approved-compact-full-gizmo-2026-09-07.png)

Adobe参考のコンパクトな軸間ハンドル構成を採用。既存FullモードのMove/Rotate/Scale再帰描画を専用描画・専用ピックへ置き換える。

- 3方向の小さい矢印／軸線: 移動。
- 軸上の小さい四角: 軸別スケール。
- 軸間の曲がったグリップ: その平面に垂直な軸の回転。
- 中央の白い四角: 均等スケール。
- 見た目とヒット位置はfullHandleForを共用。離散ハンドルを軸線より先に判定する。
- Fullからドラッグに入っても専用配置を維持。既存のドラッグ開始・変更・終了経路を使用する。
- XYZの色は参考画像に合わせた黄緑・ピンク・水色。個別ギズモの色は変更しない。

形状はGPUプリミティブとして実装し、画像をそのまま描画するものではない。回転グリップは曲線の太い線、移動矢印は小さな平面三角形。画面基準移動や平面スケールは専用Move/Scaleモードを使用する。

差分の空白を確認。ビルド・テスト・実画面は未確認。特に斜め視点のハンドル重なり、Local/World/View、スケール・回転後のピック位置、Undo/キャンセルは実機確認が必要。

入口は既存コマンドパレットの `Tool: Full Gizmo`。Selection/Allの既定挙動を変えず、専用Full値で3Dギズモを切り替える。2D専用変形ハンドルはこのモード中は非表示。
