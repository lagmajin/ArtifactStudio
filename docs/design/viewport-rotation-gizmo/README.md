# Viewport rotation gizmo

**最終更新:** 2026-09-07

[承認済み画像](approved-rotation-gizmo-2026-09-07.png)

Artifact3DGizmo の既存回転モードへ反映。太いトーラスを細いGPUラインへ置き換え、奥側を減光。軸色を保った選択強調、画面基準リング、XYZラベル、ドラッグ範囲の半透明扇形、15度目盛り、白いドラッグ位置マーカー、アンバー角度表示を追加。

既存の当たり判定・回転更新・Undo経路を維持。表示角度は実際の回転差分から算出する。360度超の扇形は1周に制限し、数値は差分を表示。表示は既存Diligentプリミティブとテキスト描画経路を使用する。

ビルド・テスト・実画面確認は未実施。透視／平行投影、Local／World／View、画面基準回転、スナップ、DPIとズームにおける文字位置・サイズは実機確認が必要。
