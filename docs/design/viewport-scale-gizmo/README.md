# Viewport scale gizmo

**最終更新:** 2026-09-07

[承認済み画像](approved-scale-gizmo-2026-09-07.png)

既存のArtifact3DGizmoへ反映。軸先端・中央の立方体を画面向きの小さい四角に変更。軸色を維持し、操作中は白い輪郭と太い軸で強調。平面ハンドルは既存操作を利用する。

倍率はドラッグ開始値に対する各軸の比率をアンバーで表示。開始値ゼロ付近は未定義としてダッシュを表示。既存バウンディングボックスがある場合は、開始時のサイズを破線で表示する。

描画経路は既存Diligentプリミティブを利用し、ヒット判定・変更・Undo経路は維持。モックの一括XYZ表示とは異なり、均等操作でも各軸の実際の倍率を表示する。

差分空白チェックのみ実施。ビルド・テスト・実画面確認は未実施。
