# AE エコシステム: プラグイン・スクリプト流用アイデア集 (2026-07-04)

> AE の代表的なサードパーティ製プラグイン/スクリプトが提供する機能から Artifact に移植/応用できそうなものを収集。

---

## 🎬 アニメーション補助系

### Motion 4 / Flow (mt. mograph)

| 機能 | 概要 | Artifact 応用 |
|---|---|---|
| **アンカーポイント一括移動パネル** | 9方向＋任意座標にアンカーポイントを即移動 | 選択レイヤーの anchor をビューポート上のミニパネルで一括操作 |
| **Elastic/Bounce/Expo 一発適用** | 選択キーフレームに物理ベースのイージングを数値入力なしで即適用 | F9 の上位互換。ビューポートに減衰/バウンスのプリセットパレット |
| **Sequencer（レイヤー連続配置）** | 複数レイヤーを時間方向に等間隔/スタガーで自動配置 | Sequence Layers の高度版。オフセットやフェード重なり付き |
| **Null Creator** | 選択レイヤー群の中心にヌルを自動作成し親子付け | 選択レイヤー群に自動で親レイヤーを作成しピボット管理 |
| **Clone ツール** | 選択レイヤーをグリッド/円形/ライン状に複製 | Cavalry Duplicate Array / C4D Cloner 相当 |
| **Warp プリセット** | バナー/フラッグ/波/魚眼などプリセット変形をワンクリック | シェイプ/テキスト向け変形プリセットのビューポート即時プレビュー |
| **カーブエディタ オーバーレイ** (Flow) | タイムラインに行かずにビューポート上でイージングカーブを編集 | キーフレーム間の補間をビューポートで直接編集 |
| **Spring/Bounce 物理シミュレーション** | 選択プロパティに減衰振動/バネの動きを自動生成 | プロパティジェネレータとして物理ベースアニメーション |

### Duik Bassel

| 機能 | 概要 | Artifact 応用 |
|---|---|---|
| **IK（インバースキネマティクス）** | 末端をドラッグすると鎖状のリグ全体が追従。ビューポート直操作 | Puppet Tool の発展形。複数ピンを鎖状接続して IK チェーン化 |
| **ボーン/ジョイント表示** | リグ構造を色付きの骨格線でビューポート常時表示 | 3D レイヤーのリグ可視化 |
| **オートリグ** | キャラクター用の歩き/走りプリセットリグを自動生成 | Puppet Tool の上位レイヤー。リグライブラリ |
| **モーフィング補間** | 2つのパス間を補間してミドルポーズを生成 | Shape レイヤーの Morph Map 機能

## 🎨 ビジュアル / エフェクト系

### Trapcode Particular / Form (Red Giant)

| 機能 | 概要 | Artifact 応用 |
|---|---|---|
| **パーティクルプレビュー in Viewport** | 3D 空間にパーティクルをリアルタイム表示。エミッター位置/方向をギズモで直接編集 | パーティクルエミッターのビューポート直操作 |
| **エミッター形状可視化** | 球/箱/円柱/グリッドなどエミッター形状を半透明の枠で表示 | ジェネレータ範囲の可視化 |
| **物理空間（Wind/Gravity/Turbulence）可視化** | 風向き矢印、重力方向、乱流範囲をビューポートにオーバーレイ | フィールド（力場）のビューポート可視化。Live Field Authoring の基礎 |
| **パーティクルパスプレビュー** | 軌跡を残像として表示 | Motion Trail のパーティクル版 |

### Optical Flares / Saber (Video Copilot)

| 機能 | 概要 | Artifact 応用 |
|---|---|---|
| **光源位置のビューポートドラッグ配置** | ビューポート上でドラッグしてフレア/光源位置を直感的に設定 | ライト/エミッター位置の直感的配置 |
| **リアルタイムプレビュー** | エフェクトパラメータ変更が即座にビューポートに反映 | 全エフェクト共通要件。発光系は特に即時フィードバックが重要 |
| **プリセットブラウザ＋プレビュー** | エフェクトプリセット一覧をグリッドサムネイルでインライン表示 | 現在の comp に適用した姿をサムネイル化 |

### Plexus 3 / Newton 3 / Element 3D

| 機能 | 概要 | Artifact 応用 |
|---|---|---|
| **点と線のジオメトリ生成** (Plexus) | レイヤー位置を頂点に頂点間を線で結ぶジオメトリを生成＋ビューポート表示 | データ可視化/インフォグラフィックスのプロシージャル生成 |
| **物理ボディ定義** (Newton) | レイヤーに物理タイプ（静的/動的）と密度/摩擦/反発を割り当て | レイヤーの物理プロパティをビューポート上で視覚的に設定 |
| **物理シミュレーションリアルタイムプレビュー** (Newton) | 再生ボタンで物理演算をその場で実行＋結果をキーフレーム化 | Simulate Mode そのもの |
| **3D モデル直接インポート＋ビューポート表示** (Element 3D) | OBJ/C4D を読み込みテクスチャ付きで表示 | Contents Viewer の 3D 機能を Composition Viewport に統合 |
| **グループ/パーティクル複製** (Element 3D) | 3D モデルをグリッド/ランダム/円形に複製 | C4D Cloner の 3D 版 |

## 🧰 ワークフロー効率化系

| プラグイン | 機能 | Artifact 応用 |
|---|---|---|
| **FX Console** (Video Copilot) | Ctrl+Space でエフェクト/コマンド検索＋即適用 | C4D Commander/QGIS Locator Bar。全コマンドのインクリメンタル検索 |
| **FX Console** | ワンキーでスナップショット取得、別キーで半透明オーバーレイ比較 | Gallery Still Store の簡易版 |
| **Overlord** (Battle Axe) | AI↔AE 間のライブリンク。外部編集→即 AE 反映 | Figma/SVG↔Artifact 双方向パス転送 |
| **KBar** | ユーザーがスクリプト/エクスプレッションを割り当てたカスタムツールバー作成 | Panel Toolbar カスタマイズ。コンテキスト依存ボタン付き |
