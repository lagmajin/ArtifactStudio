# M-AI-SUGGEST 自動提案・アシスタント機能 (2026-06-02)

既存のAI機能（ExpressionCopilot, AIClient）とは別物。LlamaAgent + ToolBridge を活用して、**モーションデザイナーの作業を先回りして提案する**機能群。AEにない最大の差別化領域。

これまでの99機能と重複しない20項目。

---

## X-A: キーフレーム自動提案（全自動）

### X-A1: 選択範囲からのモーション自動提案
選択したキーフレーム群から「意図する動き」を推定し、残りの部分を自動補完。

- [ ] 選択キーフレームのパターン分析（加速・減速・振動・周期的変化）
- [ ] パターンマッチ（既存のモーションライブラリと照合）
- [ ] 未選択区間の自動補完（3パターン提案、ユーザー選択）
- [ ] 補完結果の編集（調整可能なパラメータ）

**既存資産**: `AnimatableValueT::at()` による補間はあるが、パターン認識からの自動提案はない。
**見積**: 12-18h

### X-A2: 新規レイヤーのキーフレーム自動生成
「このレイヤー、どう動かす？」を自動で3パターン提案（フェードイン＋スライド、バウンスイン、弾性アニメーションなど）。

- [ ] レイヤータイプに応じたテンプレート（テキスト→フェード/スライド、画像→ズーム/パン）
- [ ] プロジェクト全体のトーン分析（既存キーフレームのイージング分布から傾向推定）
- [ ] 3パターンをプレビューサムネイルで一覧表示
- [ ] 選択 → 即座にキーフレーム適用

**見築**: 10-16h

### X-A3: 選択キーに「いい感じのイージング」を自動提案
選択キーフレーム間の速度変化を分析し、最適なイージングを自動提案（「動き出しが遅すぎる→EaseOut推奨」など）。

- [ ] 現在のイージングの速度曲線を分析
- [ ] 不自然な速度変化を検出（急加速/急停止/振動）
- [ ] 改善案を3つ提示（差分プレビュー付き）
- [ ] ワンクリック適用

**見築**: 8-12h

## X-B: エフェクト自動提案

### X-B1: 分析 → エフェクト提案
「この映像、空が暗い」を検出 → 「明るさ補正＋空のマスク」を提案。

- [ ] フレーム分析（ヒストグラム/輝度分散/色分布/エッジ検出）
- [ ] 問題検出（露出不足/白飛び/色かぶり/ノイズ/手ブレ）
- [ ] 修正エフェクトとパラメータを自動提案
- [ ] 提案はInspectorパネルにカード表示（Apply/Cancel）

**見積**: 16-24h

### X-B2: エフェクトの自動パラメータ調整
エフェクトを追加したときに「それっぽい値」を自動設定。Blurなら「映像の解像度に応じた適切な半径」など。

- [ ] 映像の解像度・アスペクト比から初期パラメータを推定
- [ ] エフェクトタイプごとの初期値テーブル
- [ ] 時系列変化パラメータの自動設定（「このエフェクトは時間とともに強くなる」など）

**見積**: 6-10h

### X-B3: エフェクト組み合わせ提案
「ドロップシャドウ＋グロー」などのよく使う組み合わせを提案。ユーザーの使用履歴から学習。

- [ ] よく使うエフェクト組み合わせの統計
- [ ] プロジェクト全体で使われているエフェクト傾向から関連提案
- [ ] 組み合わせをワンクリックで一括追加

**見積**: 8-12h

## X-C: レイアウト＆構成自動提案

### X-C1: 複数レイヤーの自動整列提案
選択レイヤーの配置から「グリッド」「中央揃え」「黄金比」「三分割」を自動提案。

- [ ] レイヤーバウンディングボックスの分析
- [ ] 配置候補の算出（グリッド/水平/垂直/中心/黄金比）
- [ ] プレビューオーバーレイ＋選択適用
- [ ] アニメーション付き整列（一斉フェードインなど）

**見積**: 8-12h

### X-C2: Composition 設定の自動提案
読み込んだ素材の解像度・長さから最適なコンポジション設定を提案。

- [ ] 全素材の最大解像度・アスペクト比・フレームレートを分析
- [ ] 「HD 1080p 29.97fps / 4K 23.976fps」など適切な設定を自動提案
- [ ] 背景色・ピクセルアスペクト比も自動
- [ ] 「採用」「カスタマイズ」選択可能

**見積**: 4-6h

### X-C3: タイムラインの自動カラーコーディング
レイヤー種類（動画/画像/テキスト/シェイプ）に応じて自動でカラーラベルを割り振る。

- [ ] レイヤータイプ判定 → 自動カラー割り当て
- [ ] ユーザーがカスタマイズ可能（「動画は青、テキストは緑」）
- [ ] すでに手動で色がついているものは維持

**見積**: 4-6h

## X-D: 自動アニメーションプリセット提案

### X-D1: 「このテキスト、どうアニメートする？」提案
テキストレイヤーを選択 → コンテキストに応じたテキストアニメーションを提案。

- [ ] テキスト長・フォントサイズ・レイアウトの分析
- [ ] 提案：タイプライター / フェード文字ずつ / バウンスイン / スケールイン / 回転出現
- [ ] アニメーションプレビュー（ループ再生）
- [ ] 選択 → キーフレームとテキストアニメーターを自動設定

**見積**: 10-16h

### X-D2: シェイプレイヤー自動モーフィング提案
2つのシェイプパスの中間フレームを自動生成。パスが似ていればモーフィングも自動提案。

- [ ] 2つのパスの形状類似度を計算（Hausdorff距離/フーリエ記述子）
- [ ] 類似度が高い → モーフィングアニメーション提案
- [ ] 中間フレームを自動生成（キーフレームとして配置）

**見築**: 12-18h

### X-D3: ループアニメーション自動生成
選択したキーフレーム範囲を自動ループ。自然な継ぎ目になるよう調整。

- [ ] ループ開始/終端の値・速度の差を分析
- [ ] 自然な継ぎ目になるよう前後数フレームを自動調整
- [ ] ループ範囲のキーフレーム自動追加
- [ ] ループタイプ提案（Cycle / PingPong / Offset）

**見積**: 6-10h

## X-E: オーディオ→モーション自動提案

### X-E1: ビートに合わせたキーフレーム自動配置
音声トラックのビートを検出 → ビート位置にキーフレームを自動配置。スケール/位置/不透明度などをビート同期。

- [ ] ビート検出（BPM推定）
- [ ] ビート位置にキーフレームを規則的に配置
- [ ] 各ビートでの値設定（スケール 100%→120%→100% など）
- [ ] ビートトラック（タイムライン上にビート位置を表示）

**見積**: 10-16h

### X-E2: 音声の強弱 → プロパティ自動マッピング提案
音量/スペクトラム分析 → 「音量が大きいところでスケールUP」などのマッピングを自動で設定。

- [ ] 音声エンベロープを抽出（RMS/ピーク）
- [ ] 周波数帯域分析（Low/Mid/High）
- [ ] プロパティとの相関が高い組み合わせを自動提案
- [ ] マッピング強度・反応速度調整

**見積**: 12-18h

### X-E3: 音楽ジャンル → モーションスタイル提案
音楽のジャンルを分析 → 合うモーションスタイルを提案。EDM→速いカット/弾むアニメーション、バラード→スローなフェード/クロスディゾルブ。

- [ ] 音楽分析（BPM + 周波数分布 + リズムパターン）
- [ ] ジャンル推定（EDM / HipHop / Pop / Classical / Jazz）
- [ ] ジャンル→モーションテンプレートマッピング
- [ ] テンプレート一覧表示＋ワンクリック適用

**見積**: 8-12h

## X-F: アセット・プロジェクト自動整理

### X-F1: アセットの自動タグ付け
インポートした素材を自動分析 → タグ付け（「空」「人物」「テキスト」「ロゴ」「夜景」など）。

- [ ] OpenCV シーン認識 / 色分析 / テキスト検出
- [ ] タグの自動割り当て（プロジェクトパネルに表示）
- [ ] タグ検索（「空」でフィルタ）
- [ ] 未分類アセットのハイライト

**見積**: 16-24h

### X-F2: 使用状況分析 → 未使用素材の削除提案
プロジェクトで使っていない素材を検出 → 「この素材、使ってないけど消す？」と提案。

**見積**: 4-6h

### X-F3: 類似素材の重複検出
同じファイルが複数回インポートされている、または似た内容の素材を検出。

- [ ] ファイルハッシュ比較
- [ ] サムネイル類似度比較（pHash）
- [ ] 重複一覧表示＋統合提案

**見積**: 8-12h

## X-G: 書き出し自動提案

### X-G1: プラットフォーム別最適設定提案
「YouTubeに書き出す」→ 解像度・コーデック・ビットレートを自動最適設定。

- [ ] プラットフォーム設定DB（YouTube / Instagram / X / TikTok / Vimeo）
- [ ] プロジェクトの内容から最適な設定を自動選択
- [ ] サイズ見積もり表示

**見積**: 6-10h

### X-G2: レンダリング時間予測
現在のプロジェクトを分析 → 残り時間・出力ファイルサイズを予測。

- [ ] レイヤー数・エフェクト数・解像度・長さから推定
- [ ] 過去のレンダリング実績から学習（初回は汎用モデル）
- [ ] 設定変更時の予測更新

**見積**: 10-16h

## X-H: パフォーマンス自動提案

### X-H1: フレーム落ち検出 → 改善提案
フレームレートが低下したとき、原因レイヤーと改善案を自動表示。

- [ ] リアルタイムFPS監視
- [ ] 各レイヤーのレンダリング時間計測
- [ ] 原因レイヤーの特定＋改善案（「このエフェクトをオフにする」「解像度を下げる」「プロキシを使う」）
- [ ] 改善案のワンクリック実行

**見積**: 12-18h

### X-H2: 自動プロキシ管理
重い素材を自動検出 → プロキシ生成を提案・自動実行。

- [ ] 素材の実解像度 vs コンポジション解像度を比較
- [ ] 過剰に大きい素材を検出（4K素材を1080pで使っているなど）
- [ ] プロキシ自動生成＋切り替え
- [ ] 完了通知

**見積**: 8-12h

## X-I: 学習・パーソナライズ

### X-I1: ユーザーの操作パターン学習
頻繁に使う機能・エフェクト・ショートカットを学習 → カスタムツールバーを自動作成。

- [ ] 使用頻度の記録（エフェクト/ツール/メニュー）
- [ ] 週ごとの使用統計
- [ ] 「よく使うもの」ツールバーを自動生成
- [ ] 未使用機能のお知らせ（「この機能、知ってる？使ってみる？」）

**見積**: 12-18h

### X-I2: プロジェクトテンプレートの自動作成
現在のプロジェクト構成から、テンプレート化を自動提案。

- [ ] プロジェクト構造分析（フォルダ構成・レイヤー種類）
- [ ] テンプレートとして価値があるか判定
- [ ] 編集可能パラメータの自動抽出
- [ ] 「このプロジェクト、テンプレートにしませんか？」通知

**見積**: 6-10h
