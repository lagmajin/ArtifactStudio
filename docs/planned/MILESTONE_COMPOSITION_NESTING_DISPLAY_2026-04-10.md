# コンポジションのネスト表示改善

**最終更新:** 2026-08-15
**マイルストーン**: M-CO-2 Composition Nesting Display Enhancement
**作成日**: 2026-04-10
**見積もり**: 7-9h

## 2026-08-15 現行コード照合

- ✅ `PreComposeManager` は親子 composition、precomp layer、階層、親参照、循環可能性、時間変換を管理する。Project Health Checker には循環参照検出もある。
- ✅ Timeline の Precomp layer は専用アイコン／バッジ／capability 表示を持ち、コンテキストメニューから「コンポジションを開く」、複製、名前変更、precompose／unprecompose を操作できる。
- ✅ `ArtifactProjectService::changeCurrentComposition()` と AI／Timeline の呼び出し経路により、ネスト先の編集画面へ切り替えられる。Precompose の undo／restore と保存復元も実装されている。
- ⚠️ 旧案の Project View におけるツリー型インデント、ネストレベル色分け、使用回数／未使用表示、使用箇所一覧は、現行コード上で一体化した専用 UI としては確認できない。
- ⏳ breadcrumb／親へ戻る導線、依存関係のリアルタイム可視化、未使用整理、設定による表示切替、ネスト表示の runtime QA は未完了。

## 概要

After Effects のプロジェクトパネルで、プリコンポジションの階層構造をよりわかりやすく表示する。
複雑なプロジェクト構造の理解を助け、操作ミスを防ぐ。

## 機能仕様

### 階層表示の改善
**プロジェクトパネル拡張:**
- プリコンポジションのインデント表示
- ネストレベルの色分け
- 使用状況の視覚化 (使用中/未使用)

**表示例:**
```
Project
├── Main Comp
│   ├── Precomp A (使用中)
│   │   └── Precomp B (使用中)
│   └── Precomp C (未使用) [グレー表示]
└── Archive
    └── Old Precomp (未使用)
```

### 依存関係の視覚化
**使用状況表示:**
- プリコンポジションの使用回数表示
- 循環参照の警告表示
- 未使用プリコンポの自動整理

### インタラクション改善
**操作支援:**
- プリコンポジションのドラッグ&ドロップ移動
- コンテキストメニューでの使用箇所表示
- ダブルクリックでの編集画面切り替え

### 実装要件
- 既存プロジェクトパネル拡張
- リアルタイム依存関係更新
- 設定で表示オプション変更可能
- パフォーマンス最適化

### 実装場所
- `Artifact/src/Widgets/Project/ArtifactProjectPanelWidget.cppm` (拡張)
- 設定項目: `Preferences > Project > Nesting display`

## 技術的考慮
- 依存関係グラフの構築
- メモリ使用量の最適化
- プロジェクト読み込み時の処理時間

## AEとの差別化

- 循環参照の自動検出
