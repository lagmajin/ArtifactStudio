# Misc Feature Ideas

このファイルは、まだ正式なマイルストーンに切り出す前の「実装するかもしれない候補」を雑に置いておくメモです。

## Layer / Timeline

- レイヤーをグループにまとめて折りたたむ
  - AE のプリコンプなしで、複数レイヤーをひとまとめに見せたい
  - 表示整理と操作単位の両方に使えるとよい
  - 関連候補: `MILESTONE_LAYER_GROUP_SYSTEM_2026-03-27.md`

- 複数レイヤーを同時にトリム
  - in/out を一括で詰める、伸ばす、揃える
  - タイムライン操作の効率化に効く

- エフェクトの on/off を一括トグル
  - デバッグ用
  - 選択レイヤー、選択エフェクト、全体の切替を想定

## Context Menu / Inspector

- 右クリックメニューのカスタマイズ
  - レイヤー種別ごとに出す項目を変えたい
  - ユーザーがよく使うコマンドを前面に出せるようにしたい

- カラーグレーディングの「強度」スライダーを全エフェクトに共通で追加
  - 各エフェクトの効き具合を統一的に制御したい
  - デバッグにも本番にも使える可能性がある

## Compare / Diff

- バージョン間の diff 表示
  - 何が変わったかを視覚的に見せたい
  - レイヤー、プロパティ、ショット、レンダー結果などを比較対象にできるとよい
  - 関連候補: `MILESTONE_REVIEW_WORKSPACE_2026-04-03.md`

## Export / Render

- 複数解像度を一括出力
  - SNS 用、クライアント用、マスターを同時に出したい
  - プリセットベースのバッチ出力があると便利

- レンダー完了を Slack / Discord に通知
  - 長時間ジョブの完了確認をしやすくする
  - ローカル完了通知とリモート通知を分けられるとよい

## Health / Diagnostics

- プロジェクトの健康診断を定期実行してレポート生成
  - 不足ファイル、壊れた参照、未使用アセット、重い構成を検出したい
  - 定期実行して履歴を残せると便利
  - 関連候補: `MILESTONE_PROJECT_FILE_VALIDATION_SPELL_CHECK_2026-03-26.md`

## Notes

- ここにあるものは、まだ優先順位を確定していない候補です。
- まとまったら、それぞれを正式な milestone / phase に分ける。
- 既存の正式マイルストーンと重なるものは、そちらを優先して参照する。

## Static audit follow-up (2026-07-25)

候補を現行ソースと照合した。関連する基盤として、Keyframe の一括編集、Asset の source health snapshot、Core の ValidationRules / DiagnosticEngine、Contents Viewer の compare 設定、レイヤーグループの説明登録は確認できる。ただし、これらは本メモの各 UX を完了した証拠ではなく、既存の正式マイルストーンと重複するものはそちらで管理する。

現時点で専用機能として未確認なのは、複数レイヤーの一括 trim、選択範囲の effect on/off 一括操作、右クリックメニューのユーザー編集、全エフェクト共通 intensity UI、複数解像度のプリセット一括出力、Slack / Discord 通知である。健康診断と比較表示は基盤があるため、正式マイルストーンへの切り出し時に既存実装を再利用する。

このファイルは候補メモのため、完了扱いにはせず、次の優先順位付けで正式マイルストーンへ分割する対象として維持する。
