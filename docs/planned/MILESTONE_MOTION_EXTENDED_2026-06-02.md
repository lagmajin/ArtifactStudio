# M-MOTION-EXTRA Motion Designer Extended Milestones (2026-06-02)

先に作成した7マイルストーンに加え、さらなるモーションデザイナー向け機能をカテゴリ別にまとめる。

---

## カテゴリA: ペイント & ロトスコープ（Priority 1）

### A-1: Brush / Paint Tool
ブラシで直接レイヤーに描画。色・サイズ・フロー・不透明度を指定。

- [ ] Composition Editor 上でブラシ描画（マウス/ペンタブ対応）
- [ ] ブラシ設定（サイズ、フロー、不透明度、色）
- [ ] 各ストロークを個別のプロパティとして保持（undo対応）
- [ ] フレームごとの描画（rotoscope painting）

**見積**: 16-24h

### A-2: Clone Stamp Tool
既存の画像領域をコピーして別場所にペイント。

- [ ] ソース点の指定（Alt+クリック）
- [ ] ソース位置の相対移動追従
- [ ] 異なるフレームからクローン（フレームオフセット）

**見積**: 10-16h

### A-3: Roto Brush（自動マスク抽出）
ユーザーが前景/背景ストロークを描くと、フレーム間で自動追跡するマスク。

- [ ] 前景ストローク（青）・背景ストローク（赤）のUI
- [ ] OpenCV GrabCut / 平均シフト + 輪郭追跡
- [ ] フレーム間のマスク伝播

**見積**: 20-30h（OpenCV活用で短縮可）

現在の `ChromaKeyEffect` を拡張：Spill Suppression, Edge Thin, Edge Soft, 色範囲選択。

- [ ] スポイトでキーカラー選択
- [ ] Spill Suppression（青/緑バックの色被り除去）
- [ ] Edge Thin / Edge Soft / 透明度調整

**見積**: 8-12h

### B-2: Difference Matte / Luma Key

- [ ] Difference Matte（背景プレートとの差分）

**見積**: 4-6h

## カテゴリC: コンポジション支援（Priority 2）

### C-1: タイムラインマーカーUI
`Marker` モデルは Core/NLE 層に実装済み。タイムライン上にマーカーを表示・編集するUIがない。

- [ ] タイムラインルーラー上にマーカーダイヤモンド表示
- [ ] ダブルクリックでマーカー追加。名前・色・メモ編集
- [ ] マーカー間移動（ショートカット J/K）

**見積**: 6-10h

### C-2: ガイドライン & ルーラー
`showGuides_` はあるが、ユーザーがガイドラインを**自由に追加**できない。

- [ ] ルーラー表示（画面上部・左部）
- [ ] ルーラーからドラッグでガイドライン追加・移動・削除
- [ ] ガイドラインにスナップ（既存のSnapGuideSetと統合）

**見積**: 8-12h

### C-3: Null レイヤーUI強化
Null は存在するが「Null 作成→親子付け→パラメータリンク」の導線が弱い。

- [ ] レイヤーメニュー → 「新規 Null オブジェクト」
- [ ] Null のパラメータを表示（位置のみ→全Transform + エフェクト対応）
- [ ] Null に複数のエフェクトを追加可能に

**見積**: 4-6h

## カテゴリD: 生成エフェクト（Priority 2）

### D-1: セーバー/Saber風グローエフェクト
VideoCopilot Saber 風のライトセーバーエフェクト。マスクパスに沿った発光ビーム。

- [ ] コア（白〜任意色） + グロー（広がり + 色）
- [ ] マスクパスに沿って描画
- [ ] エッジのちらつき（flicker）パラメータ
- [ ] コンポジションでの発光ブレンド

**見積**: 12-16h

### D-2: 光学フレア/Optical Flare
レンズフレアを生成。光源位置・フレア要素（グロー/リング/ポリゴン/ストリーク）をパラメータ制御。

- [ ] 光源位置：2D位置または輝度検出で自動
- [ ] フレア要素：Center Glow, Aniso Streak, Ring, Polygon, Chromatic
- [ ] プリセットブラウザ（20種類程度）
- [ ] ダイナミック（カメラ回転に追従）

**見積**: 16-24h

### D-3: パーティクルエフェクト強化
`ParticleLayer` はあるが、エフェクトとして手軽に追加できない。AEのCC Particle World相当。

- [ ] Particle エフェクトとして追加可能に（現状は別レイヤー型）
- [ ] エミッター形状（Point/Grid/Sphere/Box）
- [ ] 物理学->重力/乱気流/衝突
- [ ] パーティクル種類->スプライト/ライン/テクスチャ

**見積**: 20-30h

## カテゴリE: オーディオ・リアクション（Priority 2）

### E-1: Audio Reactor
音声波形/スペクトラムに応じてレイヤープロパティを駆動。AEのAudio Amplitude相当。

- [ ] オーディオレイヤーから「Audio Amplitude」を生成
- [ ] Left/Right/Both チャンネル選択
- [ ] 各周波数帯（Low/Mid/High）のゲート + スムージング
- [ ] Pick-Whip でアニメーションプロパティとリンク

**見積**: 10-16h

### E-2: キーフレーム補助ツール
選択したキーフレーム間を自動補完。Wiggle生成、ノイズ付加、値の反転など。

- [ ] 選択キーフレーム間の直線補完
- [ ] Wiggle キーフレーム生成（振幅・周波数指定）
- [ ] 選択キーフレームの値にランダムノイズ追加
- [ ] キーフレーム値の反転・スケール・オフセット一括変換

**見積**: 8-12h

## カテゴリH: タイムライン編集強化（Priority 2）

### H-1: Ripple / Rolling / Slip / Slide 編集ツール
ToolType の enum には存在するが、実際の動作が未実装。

- [ ] **Ripple Edit**: クリップを移動/削除 → 後続クリップが連動

- [ ] **Slip Edit**: クリップ内容だけをシフト（長さ維持）
- [ ] **Slide Edit**: クリップ移動 → 隣接クリップのIN/OUTが自動調整

**見積**: 20-30h

### H-2: カット/トリム高速化
タイムライン上のクリップ端をダブルクリック → その位置でカット。AEの `Ctrl+Shift+D` 相当。

**見積**: 4-6h

### H-3: タイムストレッチ
クリップ選択→時間伸縮（速度変更）UI。クリップ端の Alt+ドラッグで速度ランプ。

**見積**: 6-10h

## 備考: ソースコード調査で発見した既存資産

- **Marker**: Core/NLE に Marker モデル・シリアライズ完備 → **タイムラインUIのみ欠損**
- **SnapGuide**: TransformGizmo に `buildSnapGuides` / `snapValueToGuides` 完備 → **ガイドライン追加UIのみ欠損**
- **ToolType::Ripple/Rolling/Slip/Slide**: Enum 完備、ラベル表示まで実装 → **動作ロジック未実装**
- **NullLayer**: 完備 → **メニューからの導線弱い**
- **ChromaKeyEffect**: 存在 → **Spill Suppression など高度パラメータ未実装**
- **ParticleLayer**: 存在 → **エフェクト形式ではなく独立レイヤー型のみ**
- **AdjustmentLayer**: Core完備 → **コンポジションエディタ上の視覚的分かりやすさ不足**
