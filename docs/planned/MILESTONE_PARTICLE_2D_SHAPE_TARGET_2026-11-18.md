# 2D Particle の形状ターゲット

**最終更新:** 2026-11-18

既存の 2D Particle に、放出した粒を指定した文字またはシェイプレイヤーの形へ集める設定を追加する。設定は既定で無効。粒の色・サイズ・寿命は既存設定を使う。初回は静止したターゲットを扱う。

## 実装案

- Inspector にターゲットと吸引強度を出し、レイヤー ID と強度を保存する。参照切れ、自己参照、空の形状は吸引を無効にする。
- Form Particle の LayerMap が使う形状サンプリングを確認し、再利用できる入力経路から形状内の点を作る。点は粒子シミュレーションと同じ座標系へ変換する。形状変更時に上限付きの点列を準備し、各粒の移動先は seed と生成順から決める。
- 既存の固定ステップ内で移動先への吸引と減衰を適用する。フレーム中の形状取得や点列確保を避ける。保存・復元、直接 seek、連続再生の一致を確認する。

## 画像評価計画

- 人工素材は 320×180 の透明コンポジションに置く穴のある白いシェイプと、細い画線のある文字。文字はフォント名と版を記録する。空の形状、移動・回転した対象、参照の削除も含める。
- 30 fps、seed 42、同じエミッター・粒数・表示変換で、吸引無効を baseline とし、吸引有効のフレーム 1〜90 を PNG で比較する。色空間・alpha の出力契約を記録し、目視では黒と白の背景を使う。
- 無効設定の出力と baseline は同一条件で一致すること。吸引有効時は放出終了後に対象内の粒子中心率が上昇し、末尾で穴や離れた画線が読めること。対象内率、穴への漏れ、輪郭付近の alpha 分布を測り、目視で境界のにじみと連続フレームでのちらつきを判定する。対象マスクと評価領域も保存する。
- D3D12 と Vulkan で Composition View と Render Queue を確認する。担当者は直接 seek と連続再生の同一フレームも比較し、粒子更新時間とメモリを同粒数の baseline と比較する。画質と性能の数値許容差は baseline 取得後、候補の最終比較前に固定する。画像取得・判定・計測は未実施。

## 実装先

製品側の設定と保存は `ArtifactParticleLayer`、粒の更新は `ArtifactParticleGenerator` が所有する。どちらも Artifact サブモジュール内にある。親側の Render Queue 試験は出力の検証に使える。
