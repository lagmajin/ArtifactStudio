# Quick Layer Creation Dialog

**作成日:** 2026-07-10  
**ステータス:** Not Started  
**対象:** 素材・平面レイヤーの短時間作成、マスク同時生成、Layer Effect Envelope 適用

## 概要

既存の `CreateSolidLayerSettingDialog` とは別に、素材・平面・簡単なマスク・入退場エンベロープを一回の確定で組み立てる `QuickLayerCreationDialog` を追加する。

既存ダイアログは単体の平面サイズ・色設定として維持し、新ダイアログは複数の既存サービスを束ねる作成オーケストレーターとする。

## 目的

- 素材や平面を置く作業のクリック数を減らす
- 透明度とエフェクト強度の入場・退場を短時間で設定する
- 長方形・楕円などの簡単なマスクを同時作成する
- 作成後のレイヤー選択と配置を既存のレイヤー作成仕様に合わせる
- 生成全体を一回の Undo で戻せるようにする

## UI 構成

### 1. レイヤー種別

- 素材: 画像 / SVG / フッテージ
- 平面: コンポジションサイズ / 任意サイズ
- 調整レイヤー
- Null / 空レイヤー

### 2. 基本設定

- 名前
- サイズ、色、Asset Browser からの素材選択
- 選択レイヤーの直上に追加
- 作成後に自動選択

### 3. マスク

- なし
- 長方形
- 楕円
- 角丸長方形
- コンポジション全体
- Feather / Expansion

### 4. Envelope

入場・退場を独立して設定する。

- 透明度
- 対象エフェクトと強度
- 持続フレーム数
- イージング
- 透明度とエフェクト強度の関係

関係プリセット:

- 同時
- 透明度先行
- エフェクト先行
- フェード完了後にエフェクト
- エフェクト完了後に透明度
- カスタム遅延

透明度とエフェクト強度は内部では別カーブとして保持し、プリセットは相対フレーム位置を生成する。エンベロープ専用エフェクトは新設せず、既存エフェクトの animatable property に適用する。

## 作成処理

```text
入力を確定
  -> レイヤー生成
  -> 作成位置 / 自動選択を適用
  -> 簡単なマスクを追加
  -> 入場 / 退場 Envelope を追加
  -> 1つの Undo 単位として確定
```

失敗時は途中まで生成したレイヤーや付加要素を残さず、作成前の状態へ戻す。

## 実装方針

- 新規 UI: `QuickLayerCreationDialog`
- 既存の `CreateSolidLayerSettingDialog` は変更しない
- レイヤー生成は `ArtifactProjectService::addLayerToCurrentComposition(...)` を再利用する
- エフェクト追加は既存の effect service / project service 経路を再利用する
- マスクは既存 `LayerMask` / `MaskPath` の生成経路を再利用する
- 新規の公開シグナルや Qt stylesheet は追加しない
- 既存の Envelope milestone のデータモデル・評価順を前提にする

## Phase

### Phase 1: MVP

- 新規ダイアログのシェル
- 平面 / 画像素材の作成
- 長方形 / 楕円マスク
- 透明度の入場 / 退場
- 既存エフェクト1種の強度 Envelope
- 同時 / 透明度先行 / エフェクト先行
- 一括 Undo

### Phase 2: 時短プリセット

- フェード、Blur、Glow、Exposure のプリセット
- カスタム遅延フレーム
- 角丸マスク、コンポジション全体マスク
- 作成結果の要約表示

### Phase 3: 制作向け拡張

- 複数エフェクト対象
- Envelope の bake 導線
- プリセット保存
- Asset Browser からのドラッグ起点

## 非目標

- 既存の平面設定ダイアログの置き換え
- Graph Editor の代替
- 新しい専用エフェクトアルゴリズムの追加
- 自由形状の本格的な Roto 編集

## 完了条件

- 素材または平面、マスク、入退場 Envelope を一回の確定で作成できる
- 透明度先行 / エフェクト先行 / 同時の結果が意図どおり異なる
- 作成後に新規レイヤーが選択され、既存の配置仕様に従う
- 一回の Undo で一括作成全体を取り消せる
- 既存の単体平面作成ダイアログの挙動を変更しない
