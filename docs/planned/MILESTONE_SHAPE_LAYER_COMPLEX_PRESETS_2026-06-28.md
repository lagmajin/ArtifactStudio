# M-AB-7: Shape Layer 複雑プリセット形状拡張

**マイルストーンID**: M-SL-CP-2026-06-28  
**優先度**: P1 (High)  
**カテゴリ**: Shape Layer / UX Improvement  
**作成日**: 2026-06-28  
**状態**: 計画中  

---

## 🎯 目標

シェイプレイヤーに、より複雑で実用的なプリセット形状を追加し、モーショングラフィックス・UIデザイン・技術図面作成のワークフローを向上させる。

### 対象形状
1. **矢印 (Arrow)** - 方向・矢頭サイズ・尾の長さを調整可能
2. **ハート (Heart)** - クラシックなハート形状
3. **ダイヤ/菱形 (Diamond/Rhombus)** - 45度回転した正方形
4. **ギア/歯車 (Gear/Cog)** - 歯の数を指定可能
5. **十字/プラス (Cross/Plus)** - 医療・技術用記号

---

## 📋 現状分析

### 現行システム
- **基本形状**: 矩形・正方形・三角形・楕円・星・多角形・直線 (7種類)
- **ファクトリーメソッド**: `ArtifactCore::ShapeLayer::createRectangle()`, `createStar()`, etc.
- **パラメータ**: 各形状に特有のパラメータ（星の頂点数、多角形の辺数など）

### 要求される機能
- より複雑な形状の簡単な作成
- パラメートリックな制御（サイズ、比率、方向など）
- After Effectsとの互換性
- SVG入出力のサポート

---

## 🎨 詳細仕様

### 1. 矢印 (Arrow)

#### パラメータ
| パラメータ | 型 | デフォルト | 説明 |
|---|---|---|---|
| `bounds` | `QRectF` | - | 矢印全体のバウンディングボックス |
| `direction` | `ArrowDirection` | `Right` | 方向 (上・下・左・右・右上・右下・左上・左下) |
| `headRatio` | `float` | `0.3f` | 矢頭部分の長さ比率 (0.1-0.5) |
| `headAngle` | `float` | `30.0f` | 矢頭の先端角度 (度) |
| `tailRatio` | `float` | `0.7f` | 尾の太さ比率 |
| `headWidthRatio` | `float` | `1.0f` | 矢頭の幅比率 |

#### 使用例
```cpp
// 右向き矢印
auto arrow = ShapeLayer::createArrow(QRectF(0, 0, 100, 50));

// 上向き矢印、矢頭大
auto upArrow = ShapeLayer::createArrow(
    QRectF(0, 0, 100, 200), 
    ArrowDirection::Up, 
    0.4f,  // headRatio
    30.0f, // headAngle
    0.6f   // tailRatio
);
```

#### 形状生成ロジック
1. 中心線を計算
2. 矢頭部分を三角形で生成
3. 尾部分を台形で生成
4. パスを結合

---

### 2. ハート (Heart)

#### パラメータ
| パラメータ | 型 | デフォルト | 説明 |
|---|---|---|---|
| `bounds` | `QRectF` | - | ハート全体のバウンディングボックス |
| `curvature` | `float` | `0.5f` | 凹みの深さ (0.1-0.8) |
| `rounded` | `bool` | `true` | 先端を丸めるか |

#### 使用例
```cpp
// 標準的なハート
auto heart = ShapeLayer::createHeart(QRectF(0, 0, 100, 100));

// 深い凹みのハート
auto deepHeart = ShapeLayer::createHeart(
    QRectF(0, 0, 100, 100), 
    0.8f  // curvature
);
```

#### 形状生成ロジック
1. 2つの円を生成（上部）
2. 下部のV字を生成
3. ベジエ曲線で滑らかに接続
4. パスを閉じる

---

### 3. ダイヤ/菱形 (Diamond/Rhombus)

#### パラメータ
| パラメータ | 型 | デフォルト | 説明 |
|---|---|---|---|
| `bounds` | `QRectF` | - | ダイヤ全体のバウンディングボックス |
| `aspectRatio` | `float` | `1.0f` | 縦横比 (0.5-2.0) |
| `cornerRadius` | `float` | `0.0f` | 角の丸み |

#### 使用例
```cpp
// 正方形型のダイヤ（菱形）
auto diamond = ShapeLayer::createDiamond(QRectF(0, 0, 100, 100));

// 縦長のダイヤ
auto tallDiamond = ShapeLayer::createDiamond(
    QRectF(0, 0, 100, 150), 
    1.5f  // aspectRatio
);
```

#### 形状生成ロジック
1. 中心点を基準に45度回転した四角形
2. 4つの頂点を計算
3. 角の丸みを適用
4. パスを生成

---

### 4. ギア/歯車 (Gear/Cog)

#### パラメータ
| パラメータ | 型 | デフォルト | 説明 |
|---|---|---|---|
| `center` | `QPointF` | - | 中心点 |
| `outerRadius` | `double` | - | 外径 |
| `innerRadius` | `double` | `outerRadius * 0.7` | 内径 |
| `teethCount` | `int` | `8` | 歯の数 (3-32) |
| `toothDepth` | `double` | `0.2` | 歯の深さ比率 |
| `toothWidth` | `double` | `0.3` | 歯の幅比率 |
| `holeRadius` | `double` | `0.0` | 中心穴の半径 |

#### 使用例
```cpp
// 8歯のギア
auto gear = ShapeLayer::createGear(QPointF(0, 0), 50.0);

// 12歯のギア、深い歯
auto gear12 = ShapeLayer::createGear(
    QPointF(0, 0), 
    60.0,   // outerRadius
    40.0,   // innerRadius
    12,     // teethCount
    0.3     // toothDepth
);
```

#### 形状生成ロジック
1. 中心円を生成
2. 外側の歯を計算（三角形）
3. 内側の歯を計算
4. 歯と歯の間のスペースを生成
5. パスを結合

---

### 5. 十字/プラス (Cross/Plus)

#### パラメータ
| パラメータ | 型 | デフォルト | 説明 |
|---|---|---|---|
| `bounds` | `QRectF` | - | 十字全体のバウンディングボックス |
| `armWidthRatio` | `float` | `0.3f` | 腕の幅比率 |
| `armLengthRatio` | `float` | `0.8f` | 腕の長さ比率 |
| `cornerRadius` | `float` | `0.0f` | 角の丸み |

#### 使用例
```cpp
// 標準的な十字
auto cross = ShapeLayer::createCross(QRectF(0, 0, 100, 100));

// 腕の太い十字
auto thickCross = ShapeLayer::createCross(
    QRectF(0, 0, 100, 100), 
    0.4f  // armWidthRatio
);
```

#### 形状生成ロジック
1. 中心の正方形を生成
2. 上下左右の腕を生成
3. 腕を中心の正方形と結合
4. 角の丸みを適用
