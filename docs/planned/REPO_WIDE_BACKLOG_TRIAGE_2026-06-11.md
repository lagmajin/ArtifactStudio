# Repository Audit: Backlog Triage

## Purpose

Turn the repository's scattered planned work into a single prioritized map.

## Scope

- `docs/planned/*`
- milestone audit documents
- archived milestone notes

## Questions to Answer

- Which planned docs still describe active work?
- Which items are already completed but not marked clearly?
- Which milestones should be merged, split, or retired?

## Deliverable

- A ranked backlog table with status and suggested next actions.
