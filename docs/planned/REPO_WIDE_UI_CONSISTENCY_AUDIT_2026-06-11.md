# Repository Audit: UI Consistency

## Purpose

Check whether inspector, timeline, viewport, and dialog surfaces present the same concepts with the same names and behavior.

## Scope

- `Artifact/src/Widgets/*`
- `Artifact/src/Widgets/Render/*`
- menu, toolbar, and dialog entry points

## Questions to Answer

- Which actions are duplicated across surfaces with slightly different labels?
- Which states are visible in one panel but not in another?
- Where do text, timeline, and layer concepts use inconsistent terminology?

## Deliverable

- A UI terminology map and a short list of inconsistencies.
