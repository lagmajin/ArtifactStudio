# ArtifactStudio コアクラスマップ / 辞書

**日付**: 2026-07-31
**生成元**: ソースコード直接探索

---

## プロジェクト構造

```
ArtifactStudio/
├── ArtifactCore/    ← 基盤ライブラリ（型、データ構造、アルゴリズム、GPU抽象）
├── Artifact/        ← アプリケーション本体（UI、レイヤー、レンダリング、サービス）
├── ArtifactWidgets/ ← 共有ウィジェット（読み取り専用、変更禁止）
├── ArtifactRenderer/← 外部レンダラーバックエンド
├── ArtifactPr/      ← プロジェクトファイル管理
├── libs/            ← 外部ライブラリ（DiligentEngine等）
└── third_party/     ← サードパーティ（読み取り専用）
```

## 4. 主要データフロー

### 4.1 VP レンダリングパイプライン
```
CompositionRenderController::renderOneFrame()
  → drawLayers()                         // 全レイヤーを順に描画
    → drawGpuLayerToIntermediate()       // GPU 中間バッファに描画
      → drawLayerForCompositionView()    // レイヤー種別ディスパッチ
        → Artifact3DLayer::draw()        // drawMesh / draw3DLine / draw3DQuad
        → ArtifactImageLayer::draw()     // drawSprite / drawSpriteTransformed
        → ArtifactTextLayer::draw()      // テキストラスタライズ
        → ArtifactShapeLayer::draw()     // シェイプ描画
        → ArtifactParticleLayer::draw()  // パーティクル
        → layer->draw(renderer)          // fallback（動的ディスパッチ不可の型）
      → applyPointwise() / applyMasks()  // エフェクト + マスク適用
  → drawViewportCanvasOverlay()          // オーバーレイ
    → drawGrid() / drawGuides()
    → drawSelectionFrameOverlay()        // 選択フレーム（2D/投影）
    → drawMaskVertices()                 // マスク頂点 + ハンドル
  → drawGizmo3D()                        // 3D 軸ギズモ
  → drawGizmo2D()                        // 2D 変形ギズモ
  → present()                            // swap buffers
```

### 4.2 マウスイベントフロー
```
ArtifactCompositionRenderWidget::mousePressEvent()
  → Shift+Left → viewport rotation
  → Middle → pan
  → Right → context menu + hitTestTopVisibleLayer()
  → Left →
    CompositionRenderController::handleMousePress()
      → MotionSketch tool → beginSketch()
      → Puppet tool → addPin()
      → Selection+Alt → transformFieldDrag
      → Rectangle tool → beginRectangleToolSession()
      → Pen tool → hitTestMaskVertex/MaskHandle/MaskSegment
      → ProjectedFrame corner → hitTestProjectedFrameCorner → beginHandleDrag
      → 3D Gizmo → gizmo3D_->hitTest → beginDrag
      → 2D Gizmo → gizmo_->handleMousePress
      → hitTestTopVisibleLayer → select + drag start

CompositionRenderController::handleMouseMove()
  → 3D gizmo drag → gizmo3D_->updateDrag
  → 2D gizmo drag → gizmo_->handleMouseMove
  → mask vertex drag → setVertexPosition
  → mask handle drag → setMaskVertexHandle
  → layer drag → t3d.setPosition

CompositionRenderController::handleMouseRelease()
  → gizmo3D_->endDrag
  → gizmo_->handleMouseRelease
  → commitMaskEditTransaction → UndoManager::push
```

### 4.3 レンダーキューフロー
```
Composition Menu → "Add to Render Queue"
  → ArtifactRenderQueueService::addCompositions(compIds)
    → ArtifactRenderJob 生成（startFrame, endFrame, outputPath, codec...）
    → queueManager.addJob(job)
      → renderComposition(job) [CPU]  or  renderGpuFrame(job) [GPU]
        → renderSingleFrameComposition()
          → for each layer: drawLayerForCompositionView()
        → ImageExporter / FFmpeg encode
      → jobCompleted / jobFailed signal
```

### 4.4 イベントバス
```
ArtifactCore::globalEventBus().publish<T>(event)

主要イベント:
  LayerChangedEvent         → レイヤー変更（id, ChangeType::Modified/Added/Removed...）
  CompositionChangedEvent   → コンポジション変更
  ToolChangedEvent          → ツール切替
  SelectionChangedEvent     → 選択変更
  FrameChangedEvent         → フレーム変更
  PlaybackStateChangedEvent → 再生状態変更
```
