# エフェクト D&D 革新的操作アイデア集

**作成日:** 2026-07-30
**種別:** 発想メモ（マイルストーン化未定）

---

## 1. ホバープレビュー（Drag-to-Preview）

エフェクトをレイヤー上にドラッグして「置かずに」0.5 秒ホバー → ライブプレビュー発動。
ドロップで確定、ドラッグアウェイでキャンセル。

- 実装キー: `dragMoveEvent` + タイマー → 一時エフェクトインスタンス → `drawLayerForCompositionView`
- AE 未実装。試行錯誤の UX を根本から変える

## 2. エフェクトスプレー（Effect Paint on Canvas）

エフェクト選択 → キャンバス上でブラシストローク → ストローク強度 = エフェクト強度で自動マスク生成。
例: ブラー選択して背景だけ「なぞる」→ ストローク領域だけぼかし適用。

- 実装キー: パレット選択 → キャンバスがペイントモード → ストロークパス → マスク自動生成
- マスク生成パス + ブラシ描画基盤を流用

## 3. プロパティピック＆ドロップ

インスペクターのプロパティ値（不透明度 75% など）を掴んで、別レイヤーの同プロパティにドロップ。
数値、色、イージングカーブ、キーフレームごと転送可能。スポイトの全プロパティ版。

- 実装キー: `application/x-artifact-property-value` MIME + プロパティ型互換性チェック
- 実装難度: 低

## 4. オーディオ → パラメーター ビジュアルリンク

オーディオレイヤーの波形ピークを掴んで、ブラー半径スライダーにドロップ。
リアルタイムオーディオリアクティブリンク生成。周波数帯域ごとに別パラメーターへ。

- 実装キー: `application/x-artifact-audio-param-link` MIME + `ArtifactAudioReactorSystem` 接続

## 5. エフェクトチェーン組み立て（Stack Builder）

パレット内でエフェクト同士を D&D してチェーンを組み立て、まとめてレイヤーにドロップ。
Levels → Blur → Glow などをワンアクション。将来プリセット保存に発展。

- 実装キー: チェーンビルダースロット + `application/x-artifact-effect-chain` MIME

## 6. 修飾キードロップ（Modifier Drop）

ドロップ時の修飾キーでエフェクト強度を変更。
Shift = 強め、Alt = 弱め、Ctrl = マスク付き。

- 実装キー: `dropEvent` 内 `keyboardModifiers()` 分岐。実装難度: 極低

| プロパティピック＆ドロップ | 高 | 低 | プロパティシステム直結 |
| 修飾キードロップ | 中 | 極低 | なし |
| チェーン組み立て | 高 | 中 | パレット + エフェクトサービス |
| オーディオリンク | 中 | 中 | AudioReactorSystem |
