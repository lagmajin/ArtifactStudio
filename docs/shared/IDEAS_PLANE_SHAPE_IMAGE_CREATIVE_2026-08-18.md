# 平面・シェイプ・画像レイヤー クリエイティブ機能アイデア集

**作成日:** 2026-08-18
**種別:** 発想メモ（マイルストーン化未定）
**対象方針:** 静止画レイヤー → 連番画像 → シェイプ → 画像処理・合成 → 3D（2026-07-27 開発優先方針）

---

## 1. パスモーフィング（形状間補間アニメ）

星 → ハート → 歯車のような異なるシェイプを連続変形させる。AE の限定的なパスアニメを超えて、「形状が生き物のように変わる」表現。

- 既存資産: `ShapePath::interpolate(from, to, t, sampleCount)`（ArtifactCore）が実装済み
- 不足: レイヤーのキーフレーム評価経路への接続、UI 導線、保存/復元
- インパクト: 超高（モーショングラフィックスの定番表現が一気に成立）
- 実装難度: 低〜中（補間関数は既存、接続が主）

---

## 2. マルチストップグラデーション

現在は平面・シェイプとも2色グラデーション固定。多段の色停止点（任意の数・位置・色）+ 停止点ごとのキーフレーム対応で「動くグラデーションメッシュ」を実現。

- 既存資産: `FillSettings`（Solid/Linear/Radial/Conic）、平面の `ArtifactSolidFillType`
- 不足: 多段停止点データモデル、グラデーション評価、プロパティ UI
- インパクト: 高（平面・シェイプ両方に波及）
- 実装難度: 中

---

## 3. パス上のテキスト / レイヤー配置

文字やレイヤーを円・波・任意のベジェパスに沿わせる。パス上の位置・回転・オフセットをキーフレーム化できる。

- 既存資産: `TextStyle.ixx` の `ParagraphStyle::PathBinding`（startOffset/endOffset/reversePath/alignToPath）
- 不足: UI、評価経路、レイヤー配置への拡張
- インパクト: 高
- 実装難度: 中

---

## 4. シェイプへのノイズ / テクスチャフィル

平面レイヤーのノイズフィル（`M-SOLID-NOISE`）をシェイプの Fill にも適用。ノイズの動きがシェイプ形状にマスクされる。

- 既存資産: `ProceduralTextureGenerator`、`MILESTONE_SOLID_LAYER_NOISE_FILL_2026-08-18.md`
- 不足: シェイプ Fill への接続
- インパクト: 中（平面ノイズフィル完成後の横展開）
- 実装難度: 低

---

## 5. 画像 → シェイプ自動ベクター化

画像を閾値・ポスタライズして輪郭抽出し、`ShapePath` へ変換する。ラスタ素材をベクターとして編集・アニメできる橋渡し。

- 既存資産: `ShapePath`、`ShapeLayer::fromPainterPath`、`ShapePath::triangulate`、OpenCV 基盤
- 不足: 輪郭トレース（または marching squares）→ ShapePath 変換
- インパクト: 高（画像レイヤーとシェイプレイヤーの融合）
- 実装難度: 中

---

## 6. ピクセルソート

色相・明度・方向で画素を並べ替える Glitch / Synthwave 系表現。

- 既存資産: GPU コンピュートパイプライン（`ProceduralTextureComputePipeline` 等）
- 不足: ソートアルゴリズム + パラメータ（方向・閾値・バンド幅）
- インパクト: 中（差別化表現）
- 実装難度: 中

---

## 7. 深度駆動パララックス変位

画像自体の深度マップ（グレースケール）をソースにした擬似3D視差。視点を動かすと手前と奥が異なる速度で動く。

- 既存資産: `DisplacementMap` エフェクト、`ArtifactImageLayer` の source reframe
- 不足: 深度マップ → 視差レンダリングの専用経路
- インパクト: 中〜高（画像が立体になる）
- 実装難度: 中

---

## 8. パターン / タイルフィル

チェッカー、ブリック、ヘクス、ドット、ストライプ、ハーフトーン、スキャンライン等の幾何パターンを平面・シェイプのフィルとして提供。

- 既存資産: `ProceduralTextureGenerator` の派生として実装可能
- 不足: パターン生成器、パラメータ（セルサイズ・角度・色）
- インパクト: 中（定番だが多用途）
- 実装難度: 低〜中

---

## 9. カラーパレット駆動フィル

ソース画像やコンポ全体から調和色を自動抽出し、平面・シェイプを自動配色する。色の自己記述化（`FloatColor` の色空間メタデータ）と相性が良い。

- 既存資産: `FloatColor` の operator 拡張（既存 taste）、色抽出基盤
- 不足: パレット抽出、適用 UI
- インパクト: 中
- 実装難度: 中

---

## 10. パスに沿った任意レイヤー配置（モーションパス）

画像・平面・シェイプを共通のパスに沿って配置・変形・時間オフセットする。レイヤーを「パスの粒子」として扱う発想。

- 既存資産: `ShapePath::pointAtPercent` / `tangentAtPercent` / `normalAtPercent` / `sampleEquidistant`
- 不足: レイヤー配置スケジューラ、時間オフセット、UI
- インパクト: 高（レイヤー単位のモーショングラフィック）
- 実装難度: 中〜高

## 実装優先の見立て

1. **パスモーフィング** — `ShapePath::interpolate` が既存で、キーフレーム接続だけで成立。費用対効果最大。
2. **マルチストップグラデーション** — 平面・シェイプ共通の基礎。多段停止点 + アニメで差別化。
3. **画像→シェイプベクター化** — 既存の `ShapePath` / `triangulate` 資産を活かせる。
4. **パス上のテキスト/レイヤー配置** — `PathBinding` が既存、接続が主。
5. **シェイプへのノイズフィル** — 平面ノイズフィル完成後の横展開。
