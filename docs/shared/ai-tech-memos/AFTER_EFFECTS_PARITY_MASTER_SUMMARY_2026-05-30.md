# After Effects Parity Master Summary

> 2026-05-30

## One-Line Takeaway

After Effects parity の本質は「機能数を増やすこと」より、`preview / compositing / editor UX / workflow` の契約を揃えて、制作中に破綻しない状態へ寄せること。

## What Matters Now

- `P0` は preview / cache / playback stability と compositing correctness
- `P1` は graph editor / interpolation / text animator UX / motion blur / parent propagation
- `P2` は markers / shape operators / precompose workflow / layer styles / expression completeness
- `P3` は effects / OCIO / ACES / plugin interop / templates / API coverage

## What We Already Have

- text / expression / track matte / RAM preview の土台はある
- timeline の selection / summary / cache 表示も育っている
- つまり「土台がない」のではなく、`順序` と `契約` と `UI cohesion` が未完成

## What Is Easy To Misread

- `Fill` / `100%` の問題は AE parity そのものより `viewport contract` と `coordinate system` の問題
- 外部AI の未実装率は、厳密な監査結果ではなく比較用の参考値
- `feature missing` と `workflow not cohesive` を混ぜると優先順位を誤る
