# AE 3Dフレームギズモ 要求動作一覧

**日付**: 2026-07-31
**参照**: docs/memo/BUG_3D_FRAME_GIZMO_DRAG_2026-07-31.md（既知の不具合）
**ベース**: Adobe After Effects CC の 3Dレイヤーフレームギズモ挙動

---

## 1. 共通: 3Dフレームギズモの視覚

### 1.1 投影フレーム枠
- レイヤーの localBounds を 3D カメラの view/projection 行列でビューポートに投影した位置に描画する
- 枠線はレイヤー面と同一平面上にあり、カメラ角度に応じて斜めに見える
- 選択中のレイヤーにはハイライト色（アクセントカラー）で描画
- 非選択時は表示しない（またはグレーアウト）

### 1.2 コーナーハンドル（4箇所）
- localBounds の 4隅（TL/TR/BL/BR）に矩形ハンドルを表示
- ハンドルは枠線に対して少し外側（outset）に配置し、レイヤー内容と重ならないようにする
- ハンドルサイズはビューポート投影後も視認可能な最小サイズを保つ（14-36px 程度）
- 影付きで立体感を持たせる

### 1.3 選択状態の視覚フィードバック
- 選択レイヤー: アクセントカラーの枠線 + 白/明色のコーナーハンドル
- 非選択レイヤー: 薄い枠線のみ（または非表示）
- マルチ選択時: 全選択レイヤーに枠線表示（または代表レイヤーにハンドル）

## 2. コーナードラッグによるリサイズ

### 2.1 動作概要
- コーナーハンドルをドラッグすると、レイヤーの sourceSize（と scale）が変更される
- リサイズはレイヤーのローカル空間で行われ、反対側のコーナーは固定点となる
- ドラッグ中のマウス位置は3D空間上のレイヤー平面上に投影して解釈する

### 2.2 リサイズモード
| 修飾キー | 動作 |
|----------|------|
| なし | 自由リサイズ（アスペクト比非固定）。対角線上の反対コーナーが固定点 |
| Shift | 均等スケール（アスペクト比固定）。width/height の初期比を維持 |
| Ctrl/Cmd | 中心を固定点としてリサイズ（全方向に拡大縮小） |
| Shift+Ctrl | 中心固定 + 均等スケール |

### 2.3 スナップ
- ドラッグ中、コーナー位置がコンポジション境界や他レイヤーの辺に近づいたらスナップ
- スナップ時はスナップラインを描画
- Alt キーでスナップ無効

### 2.4 リサイズ時のバッジ表示
- 現在の width × height（px）を数値バッジとして表示
- バッジはリサイズ中のフレーム近傍に配置
- テキストレイヤーの場合はテキストボックスサイズも併記

### 2.5 アンドゥ対応
- ドラッグ開始時に TransformSnapshot を取得
- ドラッグ終了時に TransformUndoCommand を UndoManager に push
- アニメーションキーフレームがある場合はキーフレーム値を更新

### 2.6 アニメーションキーフレーム連携
- 現在フレームに scale キーフレームがある場合はキーフレーム値を更新
- キーフレームがない場合、initialScale を更新（または新規キーフレーム作成）
- position キーフレームがある場合は位置も自動調整（固定点維持のため）

## 3. エッジドラッグによるリサイズ

### 3.1 動作概要
- 上下左右の辺の中央付近にエッジハンドルを表示
- エッジハンドルのドラッグで、その辺に垂直な方向のみリサイズ
- ドラッグ位置もレイヤー平面上に投影
- すべてのエッジハンドル（描画・ヒットテスト・ドラッグ）は**未実装**

### 3.2 エッジハンドルの配置と描画
| ハンドル | 位置 | 固定点 |
|----------|------|--------|
| 上辺中央 | `(centerX, top)` | 下辺 |
| 下辺中央 | `(centerX, bottom)` | 上辺 |
| 左辺中央 | `(left, centerY)` | 右辺 |
| 右辺中央 | `(right, centerY)` | 左辺 |

- エッジハンドルの見た目はコーナーハンドルよりやや小さめ（80% 程度）
- 形状はコーナーハンドルと同じ矩形（色はコーナーと異なる色でも可）
- 配置は `offsetPointAwayFromCenter` で外側にオフセット

### 3.3 各エッジのドラッグ動作
| ハンドル | 操作 | 固定点 | 変更される値 |
|----------|------|--------|-------------|
| 上辺中央 (Scale_T) | 垂直リサイズ（高さ変更） | 下辺 | scaleY と positionY |
| 下辺中央 (Scale_B) | 垂直リサイズ（高さ変更） | 上辺 | scaleY と positionY |
| 左辺中央 (Scale_L) | 水平リサイズ（幅変更） | 右辺 | scaleX と positionX |
| 右辺中央 (Scale_R) | 水平リサイズ（幅変更） | 左辺 | scaleX と positionX |

### 3.4 エッジドラッグの修飾キー
| 修飾キー | 動作 |
|----------|------|
| なし | その軸のみリサイズ |
| Shift | 均等スケール（他方の軸も同率で変更、固定点は変わらない） |
| Ctrl/Cmd | 中心固定でリサイズ（反対辺も同量移動） |
| Alt | スナップ無効 |

### 3.5 エッジドラッグのガイド線
- ドラッグ中の辺と固定辺を結ぶ垂直/水平の補助線を描画
- 固定辺の位置にガイドマークを表示

## 4. フレーム内ドラッグによる移動

### 4.1 動作概要
- フレーム内部（コーナー・エッジハンドル以外の領域）をドラッグでレイヤー移動
- 移動はレイヤーのローカル XY 平面（レイヤー面）上で行われる
- 3D 空間上の位置（positionX, positionY, positionZ）が更新される

### 4.2 移動制約
| 修飾キー | 動作 |
|----------|------|
| なし | 自由移動（レイヤー平面上の XY） |
| Shift | 軸ロック（移動開始時の主要軸方向に拘束） |
| Ctrl/Cmd | スナップ有効（コンポジション境界・他レイヤー辺にスナップ） |

### 4.3 移動時のバッジ表示
- 現在の X, Y 座標（px）を数値バッジ表示
- ドラッグ開始位置からの差分（dX, dY）も表示

### 4.4 Z軸移動
- フレームギズモ単体ではZ軸移動は不可（3D軸ギズモを使用）
- マウスホイールや修飾キー+ドラッグでZ軸移動する拡張も考えられる

## 5. フレーム回転（Z軸）

### 5.1 動作概要
- フレームの外側に回転ハンドル（リング状）を表示
- ドラッグで Z 軸周りの回転（2D回転と同じく、レイヤー面に垂直な軸）
- 回転角度に応じて leader line（中心から現在角度までの線）を表示

### 5.2 スナップ
| 修飾キー | 動作 |
|----------|------|
| なし | 自由回転 |
| Shift | 15度刻みスナップ |
| Ctrl/Cmd | スナップ無効 |

### 5.3 バッジ表示
- 現在の回転角度（度）を表示

## 6. 3D軸ギズモ連携

### 6.1 表示切替
- 3Dレイヤー選択時、フレームギズモと3D軸ギズモの両方を表示
- ツールバーでギズモモード切替（Move/Rotate/Scale/Full）
- モードに応じて表示するハンドル種別を変更

### 6.2 3D軸ギズモ（Artifact3DGizmo）の責務
- X/Y/Z 軸に沿った移動（Translate）
- X/Y/Z 軸周りの回転（Rotate）- レイヤー面に垂直なZ軸回転を除き3Dギズモ側で処理
- 均等スケール（Scale）- Z方向スケールは通常1.0固定
- スクリーン平面での移動（カメラに正対する平面）

### 6.3 フレームギズモと3D軸ギズモの役割分担
| 操作 | 担当ギズモ |
|------|-----------|
| コーナードラッグリサイズ | フレームギズモ（2D TransformGizmo） |
| エッジドラッグリサイズ | フレームギズモ |
| フレーム内ドラッグ移動（XY平面） | フレームギズモ |
| Z軸回転 | フレームギズモ（回転ハンドル） |
| X/Y/Z軸移動 | 3D軸ギズモ |
| X/Y軸周り回転 | 3D軸ギズモ |
| 均等スケール | 3D軸ギズモ |
| Z方向移動 | 3D軸ギズモ |

## 8. ダブルクリックでリセット

### 8.1 スケールリセット
- コーナーハンドルまたはエッジハンドルをダブルクリック
- scaleX と scaleY を 1.0 にリセット
- sourceSize は変更しない（scale のみリセット）
- アニメーションキーフレームがある場合はキーフレーム値を 1.0 に更新

### 8.2 回転リセット
- 回転ハンドルをダブルクリック
- rotation を 0.0 にリセット
- アニメーションキーフレームがある場合はキーフレーム値を 0.0 に更新

### 8.3 位置リセット
- フレーム中央をダブルクリック
- positionX, positionY をコンポジション中央または初期値にリセット
- 存在する場合、positionZ もリセット対象

## 9. 最小サイズ制約

### 9.1 制約値
- リサイズ後の width が 1px 未満にならないようクランプ
- リサイズ後の height が 1px 未満にならないようクランプ
- `enforceResizeMinSize()` 相当のロジックを使用

### 9.2 均等スケール時の処理
- Shift キーによる均等スケール時、一方の軸が最小サイズに達したら両軸ともその比率で停止
- 最小サイズを下回る方向へのドラッグは無視する

### 9.3 固定点の維持
- 最小サイズ制約を適用しても固定点（固定辺）の位置は変わらない
- 制約超過時は固定点ではない側の座標のみ調整する

## 10. フレームのZオーダーとカメラクリッピング

### 10.1 カメラ背面での表示
- レイヤー全体がカメラの near clip 平面より手前にある場合、フレームを非表示
- レイヤー全体がカメラの far clip 平面より奥にある場合、フレームを非表示
- 部分的にクリップ面の前後にある場合はフレームを表示するが、半透明にする

### 10.2 投影Z値による判定
- `QVector3D::project(view, proj, viewport)` の戻り値 z で判定
- `z < 0.0f || z > 1.0f` のコーナーはビューポート外 → そのコーナーのハンドルは非表示
- 全コーナーが範囲外ならフレーム全体を非表示

### 10.3 フレームのクリッピング
- ビューポート外のコーナーは描画しないが、残りの枠線はクリップして描画
- フレーム全体がビューポート外の場合は `drawSelectionFrameOverlay` 自体をスキップ

## 11. 数値入力

### 11.1 バッジのインタラクティブ化
- リサイズバッジをクリックすると、width/height を直接編集できるテキストフィールドを表示
- フィールドは現在のバッジ位置にオーバーレイ表示
- 初期値は現在の width × height

### 11.2 入力フォーマット
- `{width} x {height}` 形式で表示（例: "1920 x 1080"）
- width と height は整数 px 値
- 片方のみ入力した場合は、もう一方は自動計算（現在のアスペクト比を維持）
- 「w1920」のように接頭辞付きで単一値指定も可能

### 11.3 確定・キャンセル
- Enter: 入力を確定し、scaleX/scaleY を更新
- Esc / フォーカス消失: キャンセル、元の値を維持
- 確定時は UndoCommand を push

### 11.4 無効な入力
- 数値として解釈できない入力はエラー表示（フィールド背景を赤くする等）
- 0以下の値は拒否

## 12. 3D軸ギズモとのインタラクション優先順位

### 12.1 ヒットテストの優先順位（mousePress時）
```
1. フレームコーナーハンドル（hitTestProjectedFrameCorner）
2. 3D軸ギズモ（gizmo3D_->hitTest）
3. 2D TransformGizmo（gizmo_->handleMousePress）
4. レイヤーヒットテスト（hitTestTopVisibleLayer）
```

### 12.2 競合ケース
- フレームコーナーハンドルと3D軸ギズモの軸がビューポート上で重なった場合、コーナーハンドルを優先
- 3D軸ギズモの hitTest はコーナーハンドルの hitTest 領域を除外しないと、軸がフレームより「手前」にあるケースで軸を掴めなくなる可能性がある
- 対策: コーナーハンドルのヒット領域を3D軸ギズモの hitTest に伝える、またはギズモのZオーダーを調整

### 12.3 排他制御
- フレームギズモと3D軸ギズモが同時にドラッグ状態にならないこと
- `gizmoDragActive_` フラグで排他制御（既存の仕組みで対応済み）

### 12.4 モードによるフィルタリング
| ギズモモード | フレームハンドル表示 | 3D軸ギズモ表示 |
|-------------|-------------------|---------------|
| Move | コーナーハンドルのみ | 移動軸のみ |
| Rotate | 回転ハンドルのみ | 回転リングのみ |
| Scale | コーナー+エッジハンドル | スケールハンドルのみ |
| Full | すべて | すべて |
| None | 非表示 | 非表示 |

## 13. ガイド線の延長表示

### 13.1 コーナードラッグ時のガイド線
- ドラッグ中のコーナーと固定点（対角線上の反対コーナー）を結ぶ対角線を表示
- 対角線の色は薄いアクセントカラー、破線スタイル
- ドラッグ開始位置の元のコーナー位置に小さなマークを残す（リファレンスマーク）

### 13.2 エッジドラッグ時のガイド線
- ドラッグ中の辺と固定辺の間に垂直線を表示
- 固定辺の位置に短いガイドマークを表示

### 13.3 スナップ時のガイド線
- スナップ対象（コンポジション境界、他レイヤー辺、中心線）との間にスナップラインを表示
- 既存の `activeSnapLines_` / `activeSnapLabels_` の仕組みを活用

### 13.4 回転時のガイド線
- 中心から現在のドラッグ角度方向に leader line を表示
- 0°, 90°, 180°, 270° の位置に軽いマーク

## 14. マルチセレクト対応

### 14.1 複数レイヤーの同時リサイズ
- 複数の3Dレイヤーが選択されている場合、すべての選択レイヤーのフレームを表示
- ドラッグ操作は全選択レイヤーに同時適用
- 各レイヤーの localBounds の比率に応じて個別にリサイズ量を計算

### 14.2 複数レイヤーの包絡フレーム
- 全選択レイヤーの bounding box を包絡する外枠フレームを表示
- 包絡フレームのコーナー/エッジハンドルを操作すると全レイヤーが一律にリサイズされる

### 14.3 個別レイヤーのフレーム
- 包絡フレーム内の各レイヤーにも個別のフレームを表示（細線、薄色）
- 個別フレームのハンドルは非表示（操作は包絡フレーム経由のみ）

## 15. 実装アーキテクチャ案

### 15.1 新規クラス: ArtifactProjectedFrameGizmo
ヒットテストからドラッグ完了までの一連のインタラクションを、既存の2D TransformGizmoから分離する。

```
class ArtifactProjectedFrameGizmo {
    // 描画（既存の drawSelectionFrameOverlay を包含）
    void draw(IRenderer*, const LayerPtr&, const QMatrix4x4& view, const QMatrix4x4& proj);
    
    // ヒットテスト（hitTestProjectedFrameCorner を包含 + エッジ対応）
    HandleType hitTest(const LayerPtr&, const QPointF& viewportPos, ...);
    
    // インタラクション
    bool beginDrag(HandleType, const Ray& pickingRay);
    void updateDrag(const Ray& pickingRay);
    void endDrag();
    
    // 各ハンドルタイプ: Corner_TL/TR/BL/BR, Edge_T/B/L/R, Interior, Rotate
};
```

### 15.2 handleMousePress の変更点（擬似コード）
```
if (selectedLayer && selectedLayer->is3D() && activeTool != Pen) {
    // 1. フレームコーナーヒットテスト
    auto frameHandle = projectedFrameGizmo_->hitTest(...);
    if (frameHandle != None) {
        Ray ray = createPickingRay(viewportPos);
        projectedFrameGizmo_->beginDrag(frameHandle, ray);
        gizmoDragActive_ = true;
        return;
    }
    
    // 2. 3D軸ギズモヒットテスト
    Ray ray = createPickingRay(viewportPos);
    GizmoAxis axis = gizmo3D_->hitTest(ray, ...);
    if (axis != None) {
        gizmo3D_->beginDrag(axis, ray);
        gizmoDragActive_ = true;
        return;
    }
}
```

### 15.3 handleMouseMove の変更点
```
if (projectedFrameGizmo_->isDragging()) {
    Ray ray = createPickingRay(viewportPos);
    projectedFrameGizmo_->updateDrag(ray);
    // scaleX/scaleY/position をレイヤーに反映
    return;
}
if (gizmo3D_->isDragging()) {
    // 既存の処理
    return;
}
// 以降は既存の2D処理
```
