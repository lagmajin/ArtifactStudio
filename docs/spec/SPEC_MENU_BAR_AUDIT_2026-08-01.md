# メニューバー 現状と整理案

**日付**: 2026-08-01

---

## 1. 現在のメニュー構成（全14メニュー）

```
File | Edit | Composition | Layer | Effect | Animation | Script | Render | Time | View | Option | [Test] | Help
```

各メニューは専用クラスに分割されている（`ArtifactFileMenu`, `ArtifactCompositionMenu` など）。

## 3. 追加メニューの提案

### 3.1 新規: Rig（リグ）メニュー — 中優先度

リグ編集が本格化したら独立メニューにする価値がある。

```
リグ編集モード ON/OFF (Ctrl+Tab)
───
ボーンを追加
コントロールを追加 ▸ (Slider / Point / Angle)
IKを追加 ▸ (TwoBone / CCD)
制約を追加 ▸ (Parent / Aim / MapRange)
───
スマートボーンを編集...
───
ポーズライブラリ ▸
  ├ 現在のポーズをキャプチャ
  ├ ポーズを適用...
  └ ポーズをブレンド...
───
自動リギング...
───
ウェイトペイントモード
  ├ ブラシサイズ
  ├ 不透明度
  └ スムーズ
───
リグをJSONに書き出し...
リグをJSONから読み込み...
```

### 3.2 新規: Mask（マスク）メニュー — 低優先度

マスク専用メニュー。現在はペンツールと矩形ツールで暗黙的に作成。

```
新規マスク
───
マスクモード ▸ (Add / Subtract / Intersect / Difference)
マスクを反転
───
マスクを削除
全マスクを削除
───
マスクを複製
マスクをコピー / ペースト
───
マスクフェザー...
マスク拡張...
マスク不透明度...
───
マスクをシェイプに変換
シェイプをマスクに変換
───
クイックマスクプリセット ▸ (円形 / 矩形 / リニア / 放射)
```

## 4. 整理案まとめ

### 4.1 即時対応（追加のみ、構造変更なし）

| メニュー | 追加アクション |
|----------|---------------|
| File | `最近使ったコンポジション ▸` |
| Edit | `同位置にペースト (Ctrl+Alt+V)` |
| Composition | `選択範囲をレンダーキューに追加 ▸`（3種） / `レンダーキューに追加（詳細）...` |
| Layer | `新規 ▸ リグレイヤー` / `マスク ▸` サブメニュー / `エフェクトをコピー/ペースト` |
| Effect | `最近使ったエフェクト ▸` / `お気に入り ▸` |
| Animation | `キーフレーム補助 ▸`（Easy Ease 等） / `エクスプレッションを追加` |
| Script | `式コパイロットを開く` / `最近使ったスクリプト ▸` |
| Render | `選択ジョブをレンダリング` / `全ジョブレンダリング` / `出力フォルダを開く` |
| View | `リグオーバーレイ` / `オニオンスキン` / `セーフマージン` |
| Window | `ポーズライブラリ` / `リグ階層` |

### 4.2 将来対応（構造変更あり）

| 内容 | 説明 |
|------|------|
| `Rig` メニュー新設 | リグ編集の全機能を集約 |
| `Mask` メニュー新設 | マスク操作の全機能を集約 |
| `Time` メニュー廃止 | Composition と Animation に統合 |
| `Option` → `Edit → 設定` 統合 | AE に合わせる |

### 4.3 推奨ショートカット追加

| 機能 | キー |
|------|------|
| リグ編集モード切替 | `Ctrl+Tab` |
| ウェイトペイント | `B`（Brush と兼用） |
| ポーズキャプチャ | `Ctrl+Shift+P` |
| レンダーキューに追加（詳細） | `Ctrl+Shift+/` |
| 同位置にペースト | `Ctrl+Alt+V` |
| エフェクトをコピー | `Ctrl+Alt+C` |
| エフェクトをペースト | `Ctrl+Alt+V` |
