**日付**: 2026-07-31
**ベース**: Adobe After Effects CC Shape Tools

## Shape Tool（シェイプツール） — `ToolType::Shape`

AEのシェイプツールは、ペンツールと矩形/楕円ツールの中間的な位置づけで、プリセット図形をVP上に直接作成する。

### 1. シェイプレイヤー作成

#### 1.1 基本フロー
- ツール選択 → キャンバスドラッグ → シェイプレイヤー作成
- ドラッグ範囲がシェイプの外接矩形
- シェイプレイヤーは ArtifactShapeLayer として生成

#### 1.2 作成時の修飾キー
| 修飾キー | 動作 |
|----------|------|
| なし | 自由サイズ |
| Shift | 正円/正方形（アスペクト比1:1） |
| Alt | 中心から作成 |
| Shift+Alt | 中心から正円/正方形 |

#### 1.3 シェイププロパティのデフォルト
- 塗り: CharacterパネルのFill設定
- 線: CharacterパネルのStroke設定
- 線幅: ツールオプションから継承

### 2. シェイプのVP上編集

#### 2.1 作成後の即時編集
- 作成直後、ハンドルが表示されサイズ/形状調整が可能
- エッジ/コーナーハンドルでリサイズ
- 数値HUDに現在のサイズ表示

#### 2.2 シェイプパスの編集
- シェイプの頂点（アンカーポイント + ベジェハンドル）の編集
- ペンツールと同じ頂点操作（ドラッグ/ハンドル調整）
- パスに頂点追加/削除

#### 2.3 シェイプのプロパティ
- 塗りの色/不透明度
- 線の色/幅/不透明度
- 線の位置（内側/中央/外側）
- 線端の形状（バット/ラウンド/スクエア）
- 線の結合形状（マイター/ラウンド/ベベル）
- 破線/点線設定

### 3. 複合シェイプ（Shape Group）

#### 3.1 シェイプの合成モード
- Add（加算）
- Subtract（減算）
- Intersect（交差）
- Exclude Intersections（排他的論理和）

#### 3.2 グループ化
- 複数のシェイプパスをグループ化
- グループ単位でのトランスフォーム（位置/スケール/回転）
- グループの塗り/線の継承

### 4. シェイプのアニメーション
- パス形状のキーフレームアニメーション
- 塗り/線の色アニメーション
- Trim Paths（パスの開始/終了/オフセットのトリミング）
- Zig Zag / Pucker & Bloat / Twist などのパスオペレーター

## Rectangle Tool（矩形ツール） — `ToolType::Rectangle`

### 実装済み
- [x] ドラッグで矩形マスク作成（RectangleToolMode::Mask）
- [x] ドラッグで矩形シェイプ作成（RectangleToolMode::Shape）
- [x] QPainterPath → MaskPath::fromQPainterPath() でベジェパスに変換
- [x] beginMaskEditTransaction / commitMaskEditTransaction（Undo）

### 未実装
- [ ] **Shiftドラッグで正方形**
- [ ] **Altドラッグで中心から作成**
- [ ] **角丸半径（roundness）パラメータ**
- [ ] **角丸半径のVP上ドラッグ調整**（作成直後に角丸ハンドルを表示）
- [ ] **数値HUD**（作成中の width × height 表示）
- [ ] **作成後の即時サイズ/位置編集ハンドル**

## 実装現状まとめ

| ツール | VP操作実装率 | 主な不足 |
|--------|-------------|----------|
| Shape | 5% | ほぼ未着手（シェイプ作成・編集・複合シェイプ・アニメーション） |
| Rectangle | 50% | 修飾キー、角丸、HUD、即時編集 |
| Ellipse | 5% | ほぼ未着手（作成ロジックすらない） |

### 共通不足
- 3ツール共通: 作成時の修飾キー（Shift/Alt）サポート
- 作成後の即時サイズ編集ハンドル
- 数値HUD（リアルタイムの width × height）
- シェイプとマスクのモード切替UI
