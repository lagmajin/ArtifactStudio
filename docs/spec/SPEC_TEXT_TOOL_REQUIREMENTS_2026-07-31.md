# Text Tool 要求動作一覧

**日付**: 2026-07-31
**ベース**: Adobe After Effects CC Text Tool

---

## 1. テキストレイヤー作成

### 1.1 ポイントテキスト（クリック作成）
- キャンバスをクリック → その位置にテキストレイヤーを作成
- クリック位置がテキストのベースライン開始点
- キャレットが点滅表示され、即座にテキスト入力モード
- 現在の Character パネル設定（フォント/サイズ/色）を継承

### 1.2 段落テキスト（ドラッグ作成）
- キャンバスをドラッグ → 矩形テキストボックスを作成
- ドラッグ範囲がテキストボックスのサイズ
- 作成後、ボックスの左上からテキスト入力開始
- ボックスサイズは後からコーナー/エッジハンドルで調整可能

### 1.3 既存テキストの編集
- テキストレイヤーをダブルクリック → 編集モード
- キャレット位置をクリックで移動
- ドラッグでテキスト選択

---

## 2. テキスト編集中のUI

### 2.1 キャレット表示
- 編集中、挿入位置に点滅キャレット（縦線）を表示
- キャレット色はテキスト色とコントラストする色

### 2.2 選択範囲表示
- ドラッグ選択範囲を反転色でハイライト
- 選択範囲に対してカット/コピー/ペースト

### 2.3 編集中のキーボード操作
| キー | 動作 |
|------|------|
| 文字入力 | キャレット位置に文字を挿入 |
| Backspace | キャレット前の1文字を削除 |
| Delete | キャレット後の1文字を削除 |
| Enter | 段落テキスト: 改行 / ポイントテキスト: 編集確定 |
| Esc | 編集キャンセル（変更を破棄） |
| Ctrl+A | 全選択 |
| Ctrl+C/V/X | コピー/ペースト/カット |
| Ctrl+Z | アンドゥ |
| 矢印キー | キャレット移動 |
| Shift+矢印 | 選択範囲拡張 |

## 3. テキストプロパティ

### 3.1 Character プロパティ
- フォントファミリー
- フォントスタイル（Regular/Bold/Italic/Bold Italic）
- フォントサイズ（px）
- 行送り（leading）
- カーニング（文字間隔）
- トラッキング（単語間隔）
- 縦横比（horizontal/vertical scale）
- ベースラインシフト
- 文字色（fill color）
- ストローク（stroke）の色/幅
- 偽斜体/偽太字/オールキャップス/スモールキャップス
- 上付き/下付き

### 3.2 Paragraph プロパティ
- 左揃え/中央揃え/右揃え
- 均等揃え（最終行左揃え/中央揃え/均等）
- 左インデント/右インデント
- 段落前スペース/段落後スペース
- 先頭行インデント

---

## 4. テキストアニメーター（Text Animator）

### 4.1 アニメータープロパティ
- Position / Scale / Rotation / Opacity / Fill Color / Stroke Color / Tracking / ...
- 各プロパティに Range Selector を設定可能

### 4.2 Range Selector
- Start / End / Offset パラメータ
- アニメーションで文字単位の出現/消滅を制御
- Smoothness / Ease High / Ease Low
- Shape: Square / Ramp Up / Ramp Down / Triangle / Round

### 4.3 Wiggly Selector
- ランダムな文字単位の変動
- Wiggles/Second / Correlation / Temporal Phase / Spatial Phase
