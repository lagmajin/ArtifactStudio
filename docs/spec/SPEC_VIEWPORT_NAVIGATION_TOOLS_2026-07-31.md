# Hand / Zoom / Rotation / AnchorPoint ツール 要求動作一覧

**日付**: 2026-07-31
**ベース**: Adobe After Effects CC ビューポート操作ツール

---

## Hand Tool（手のひらツール） — `ToolType::Hand`

### 実装済み
- [x] 中ボタンドラッグでパン
- [x] Handツール選択時の左ボタンドラッグでパン
- [x] カーソル（OpenHand/ClosedHand + SVG）

### 未実装
- [ ] **Spaceキー一時Handツール**（フラグはあるが配線なし）
  - 任意のツール使用中に Space を押すと一時的に Hand ツールに切り替わる
  - Space を離すと元のツールに戻る
  - Space+ドラッグの間だけパン操作
- [ ] **慣性スクロール（モメンタム）**
  - ドラッグを離した後、速度に応じて減衰しながらスクロール継続
  - 減衰係数で徐々に停止
- [ ] **Shift+ホイールで水平スクロール**
  - マウスホイール単体 = 垂直ズーム
  - Shift+ホイール = 水平スクロール
- [ ] **マウスホイール押し込み + ドラッグでパン**
  - 中ボタンがないマウス向けの代替操作

---

## Zoom Tool（ズームツール） — `ToolType::Zoom`

### 実装済み
- [x] マウスホイールズーム（ポイント中心）
- [x] zoomInAt / zoomOutAt / zoomFit / zoomFitSelection / zoom100
- [x] キーボード: Ctrl+1 = 100%, F = fit, Shift+F = fit selection

### 未実装
- [ ] **クリックでズームイン**
  - ズームツール選択時、キャンバスクリック → クリック位置を中心にズームイン（1段階）
- [ ] **Alt+クリックでズームアウト**
  - クリック位置を中心にズームアウト（1段階）
- [ ] **矩形ドラッグで領域ズーム（Marquee Zoom）**
  - ドラッグで矩形を描画 → その範囲がビューポートいっぱいに拡大
  - ドラッグ中、矩形のプレビュー表示
  - ドラッグ方向によって、領域全体が表示されるようにズーム率を自動計算
- [ ] **スムーズズームアニメーション**
  - ズーム変更時に線形補間で徐々に遷移
  - 遷移時間: ~150ms
- [ ] **ズームツール専用カーソル**
  - 通常: 虫眼鏡（+）アイコン
  - Alt押下中: 虫眼鏡（-）アイコン

---

## Rotation Tool（回転ツール） — `ToolType::Rotation`

### 実装済み
- [x] ギズモ回転リング（TransformGizmo::Mode::Rotation）
- [x] Shift+左ボタンでビューポートキャンバス回転
- [x] 3Dレイヤーの回転（Gizmo3D）

### 未実装
- [ ] **キャンバス直接ドラッグで回転**
  - 回転ツール選択時、レイヤー上のどこかをドラッグ → 回転
  - ギズモリングにカーソルを合わせなくても回転操作が可能
  - レイヤーの中心（またはアンカーポイント）を基準に回転
- [ ] **回転アンカーポイントの視覚表示**
  - レイヤーの回転中心を十字線マークで表示
  - アンカーポイントをドラッグで再配置可能
  - AnchorPoint ツールと共通のUI
- [ ] **Shiftスナップ回転（45°刻み）**
  - Shift押しながらドラッグ → 45°刻みでスナップ
  - オプションで刻み角度を変更可能（15°/30°/45°/90°）
- [ ] **回転角度の数値HUD**
  - ドラッグ中、現在の回転角度を数値で表示
  - 例: "45.0°" をレイヤー近傍に表示
  - 正の角度 = 時計回り、負 = 反時計回り
- [ ] **回転ツール専用カーソル**
  - 回転矢印アイコン

---

## AnchorPoint Tool（アンカーポイントツール） — `ToolType::AnchorPoint`

### 実装済み
- [x] ギズモモード設定（TransformGizmo::Mode::AnchorPoint）
- [x] アンカーポイントのドラッグ移動（TransformGizmo::handleMouseMove 内）
- [x] ローカル空間でのスナップ（頂点/辺/中心）
- [x] Altキーでスナップ無効
- [x] アンカーポイント変更に伴う位置自動補正

### 未実装
- [ ] **アンカーポイントの視覚マーク表示**
  - 十字線（+）またはサークル付きクロスヘア
  - 色は白/灰色、ドラッグ中は黄色
  - サイズはズームに応じて一定の視認サイズを維持
- [ ] **アンカーポイントの数値HUD**
  - ドラッグ中に現在のアンカー位置を X, Y で表示
  - 例: "X: 960 Y: 540"
- [ ] **Ctrl+ダブルクリックで中心にリセット**
  - レイヤーの localBounds 中心にアンカーを戻す
- [ ] **コンポジション境界/中心へのスナップ**
  - 現在はレイヤー自身のローカル座標のみにスナップ
  - コンポジションの中心や端にもスナップすべき
- [ ] **アンカーポイント移動時の Undo**
  - 現在は TransformGizmo 経由の UndoManager プッシュがない（要確認）
- [ ] **専用カーソル**
  - アンカーポイントアイコン

---

## Move Tool（移動ツール） — `ToolType::Move`

### 実装済み
- [x] ギズモモード設定（TransformGizmo::Mode::Translation）
- [x] 選択レイヤーのドラッグ移動（Selectionツールと同等のロジック）
- [x] マルチセレクトのグループ移動

### 未実装
- [ ] Selectionツールと完全に同等のため、特筆すべき不足はない
- [ ] Moveツール選択時のカーソルを専用アイコンに（現在は共通）

---

## Scale Tool（スケールツール） — `ToolType::Scale`

### 実装済み
- [x] ギズモモード設定（TransformGizmo::Mode::Scale）
- [x] コーナー/エッジ/センタースケールハンドル表示
- [x] スケールドラッグ操作
- [x] 修飾キー（Altでスナップ無効）

### 未実装
- [ ] **均等スケールのデフォルトON**
  - Scaleツールでは Shift なしでも均等スケールがデフォルト
  - Shift を押すと非均等スケール（非拘束）に切り替え
  - またはオプションで切り替え可能
- [ ] **スケール率の数値HUD**
  - 現在のスケールを%表示（例: "W: 150% H: 150%"）
  - 均等スケール時は "150%" のみ
  - ドラッグ中にリアルタイム更新
- [ ] **スケール変更と sourceSize の関係**
  - Scaleツールでは scaleX/scaleY のみ変更（sourceSize 不変）→ これは正しい
  - ただし Shift+ドラッグで sourceSize を変更するモードの提供（AEにはないが便利）
