# ソフトキー

**最終更新:** 2026-10-05

## 編集仕様

ソフトキーは、後で選択してまとめて確定または破棄する仮のキーフレームである。
値・時刻・補間は通常キーと同じように評価され、プレビューとレンダリングにも反映する。
確定は仮状態だけを解除する。破棄は仮状態のキーを削除する。

タイムライン本体 (`ArtifactTimelineTrackPainterView`) の右クリックから操作する。

- プロパティ行の「ソフトキーをここに追加」: クリックしたフレームの評価値で追加する。同時刻に既存キーがある場合は変更しない。
- キー選択後の「ソフトキー → 選択キーをソフト化」: 選択した通常キーを仮状態にする。
- 「選択ソフトキーを確定」: 選択中のソフトキーだけを通常キーにする。
- 「選択ソフトキーを破棄」: 選択中のソフトキーだけを削除する。混在している通常キーは残す。

各操作は一回のUndo/Redoで扱い、キー属性と選択状態を復元する。ロック中のレイヤーは編集しない。
ソフトキーはマーカー内の中抜き・破線とツールチップで区別する。ショートカットや常時表示バッジは追加しない。

## データ

`Property.Abstract` の `KeyFrame::soft` を正とし、既定値はfalseである。
保存データとキーのclipboard payloadにbooleanの `soft` を加える。旧データで項目がない場合は通常キーとして読む。
移動・複製・時間変更・補間変更・Undo・レイヤー/テキスト/変形制御の保存復元で属性を引き継ぐ。
Core側の補間アルゴリズムやレンダラーのキー評価条件は変更しない。

既存通常キーをソフト化した後の「破棄」は削除であり、ソフト化以前の値への復帰ではない。復帰にはUndoを使う。
旧版アプリによる保存では新属性が失われる可能性があるため、旧版との往復保存は対応保証の対象外である。
