# 切り絵・ネオン点灯・時間モザイクの画像評価計画

製品接続前に、線形 RGB と straight alpha の float RGBA を入力とする CPU 参照を比較する。固定素材は手続き生成し、生成コードの版、入力 hash、解像度、設定、フレーム番号、Python と NumPy の版を評価記録に残す。数値は float のまま測り、目視用には同一の露出と sRGB 表示変換を用いる。

| 効果 | 素材・比較対象 | 判定 |
|---|---|---|
| 切り絵 | 3〜5色のベタ塗り、1px の細線、半透明ロゴ、黒白背景。原画と同色数の減色＋単一 Drop Shadow を比較に使う | 色面ごとに裏紙と影が読め、元の細線を残す。厚みゼロでは減色結果と一致。元の透明縁と影の外側を拡大し、不要な色漏れを確認する |
| ネオン | 直線と曲線をつないだ一本のパス、短い曲線、HDR 発光色。点灯なしと全点灯を端点の参照に使う | 進捗 0 で透明、1 で全区間が点灯。等しい進捗差に対する先端移動距離は弧長サンプリング幅以内で一致。半透明の発光縁を黒白背景で比較する |
| 時間モザイク | フレーム番号と移動図形を含む 24 フレーム。各セルの参照時刻から別途組み立てた画像を正解とする | 全セルが期待フレームの同一座標と完全一致。遅延ゼロで入力と一致。先頭の範囲外参照は先頭フレームに固定。順再生・逆順・直接シークを比較する |

640×360 と 1280×720 で全体、境界、細線、高輝度部の画像と座標付き crop を保存する。領域別に RGB・alpha の分位点、最大差、非有限値数を記録する。切り絵とネオンは担当者が連続フレームも目視し、意図外のちらつきや縁の破綻を確認する。合成フレームの決定的な契約には完全一致を要求する。画質の許容差は baseline を見て候補比較前に決定する。

CPU 参照では同一環境で実行時間とピークメモリを計測する。製品の性能予算は baseline 計測後、候補比較前に解像度ごとに決定する。Artifact の Preview／最終出力、D3D12／Vulkan、製品側の HDR・alpha 契約と性能は製品接続後に評価する。現時点の評価結果は未取得。
