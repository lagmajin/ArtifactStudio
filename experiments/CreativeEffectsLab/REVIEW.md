# CPU 試作の一次画像レビュー

2026-11-21 に 640×360 の暗背景 PNG を目視した。1280×720 と白背景も生成済み。2解像度の manifest はそれぞれ13ケースを記録しており、非有限値は0。これは画像生成と有限値の確認で、画質の合否は下記のとおり未確定。

| 効果 | 観察 | 残る評価 |
|---|---|---|
| 切り絵 | 楕円の下側に断面と影が見える。三角形の断面は下辺に集中し、中央の細線が紙の境界と紛れやすい | 淡色と濃色の紙を白背景でも比較する。細線と元の半透明境界を領域別に測る。現行 Drop Shadow を使った比較画像は未取得 |
| ネオン | 半分点灯の画像では直線から曲線まで光の芯が続き、先端が強く光る | 連続フレームで先端の移動距離を測る。白背景では加算発光の見え方を別途判定する |
| 時間モザイク | 行順の画像では左上から右下へ 23、21、19、17、15、13、11、9、7 の表示が確認できる | 全セルを別計算の float 参照と比較する。製品での直接シーク、逆順、先頭不足の解決は未評価 |

再生成はリポジトリルートで `python -B experiments/CreativeEffectsLab/render_examples.py`。NumPy と Pillow が必要。出力はローカルの `captures/` に置く。評価条件と未取得の証跡は [評価計画](EVALUATION_PLAN.md) を参照。

## 製品接続で確認する境界

ネオンの CPU 参照を追加確認した。長さ48 pxの水平直線を32×64 pxの float RGBA に描画し、進捗ゼロで全画素ゼロ、25/50/75/100%で期待先端の x=20/32/44/56 に不透明な芯があることを確認。先端の青は途中で約3.71、全点灯で約2.8となり、線形値1を超える発光を保持する。曲線での速度評価や製品のHDR表示は未確認。

時間モザイクの CPU 参照を追加確認した。合成した24枚の float32 RGBA（17×13、3×3のタイルで割り切れない寸法）で、画素ごとに別計算した参照と照合。行順・列順・蛇行順それぞれで順再生、逆順、飛び飛びの参照を試し、159出力が完全一致した。先頭へのクランプもこの比較に含む。遅延ゼロは3通りとも入力と完全一致。これは任意のフレームを返せる入力を使った CPU 参照の結果であり、製品のフレーム取得は未確認。

- 切り絵は、減色面、紙の断面、影を同じ float RGBA の合成経路で処理できるかを確認する。現行試作は固定パレット順で、入力の領域重なりを復元しない。
- ネオンはパスの取得と弧長計算、発光を分ける。パスの変更時に弧長表を更新し、点灯進捗だけが変化するフレームでは再利用する。
- 時間モザイクは既存 Slit Scan の累積状態をそのまま共有できない。Slit Scan は呼び出し順で位置と蓄積画像が進む。時間モザイクには現在のエフェクトより上流の画像を絶対フレームで取得する経路が必要で、履歴が空でもシーク結果を変えないことが条件になる。
