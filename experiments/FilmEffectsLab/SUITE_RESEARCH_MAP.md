## Next research priorities

1. **High confidence, medium scope — obtain the prepared paired CPU Composition alpha capture through a supported offline path.** Plan, fixtures/ROIs, manifest, and analyzer exist. Source inspection confirms the CLI `render` executor is not implemented and Python render only enqueues a job; the prepared capture therefore cannot currently produce PNG evidence without desktop interaction. User prefers Windows UI operations to be avoided, so leave this as an evidence gap until an offline capture path exists; do not switch to GUI operation.
2. **Completed source-model tranche — characterize Add Noise CPU/Composition-resident ingress differences.** `plans/add-noise-route-equation-audit-r1.json` and `plans/add-noise-composition-ingress-hdr-alpha-r1.json` cover CPU/resident/dedicated-wrapper equations, alpha-associated route hypotheses, LayerToFloat HDR clamp, and low-alpha/HDR patch grids. These remain conditional equation models: actual route selection, compiled output, GPU/backend parity, and performance are unverified.
3. **High confidence, medium scope — capture Match Grain with a fixed reference plate.** Independent plans/models now cover transfer, resolution scaling, and temporal jitter (`plans/match-grain-reference-transfer-r1.json`, `match-grain-reference-resolution-scale-r1.json`, `match-grain-temporal-jitter-response-r1.json`). Next use an identified `grain_reference` input through a supported offline capture/export path, record auxiliary resize/color-descriptor behavior, and compare real output to the model without treating the synthetic reference as ground truth. Do not launch/operate the Windows UI; the user prefers offline capture.
4. **Medium confidence — compare Core FilmGrain and legacy FilmEffectProcessor only if a consumer is identified.** Current searches found no active C++ caller for those paths; do not treat their equations or preset values as normal Composition output.
5. **Completed source-model tranche — extend corrected Halation boundary response to finite highlight clusters.** `plans/physical-halation-highlight-cluster-edge-response-r1.json` covers 432 combinations across 128–1024px, Spread15/50/100, sigma0/1/4/12 and center/edge/corner positions. Active highlights touch the frame border while the source cluster remains fully in-bounds. At 256px/Spread50, sigma1/4/12 clusters have lower total red diffusion energy at edges/corners than center, while peak values can be slightly higher. This remains a synthetic opaque neutral model.
6. **Completed source-model tranche — compare Add Noise / Film Grunge grain morphology at matched RMS.** `plans/grain-family-matched-strength-spectrum-r1.json` preregistered a 28x28, 128-seed comparison and calibrated Add Noise mono/color Amount per Size to Film Grunge's default green residual standard deviation. At Size1.5 the modeled spectra and directional correlations differ despite RMS matching; tone-edge clipping also differs because Add Noise clamps RGB while the Film Grunge grain equation does not. Core FilmGrain and legacy FilmEffectProcessor were excluded because no active production consumers were found. Next evidence tranche: preserve the model output and wait for a supported offline runtime capture route; user prefers no normal Windows UI operation. No app output, GPU parity, perceptual equivalence, or quality verdict is established.
7. **Completed source-model tranche — compare cross-family grain temporal response at matched initial RMS.** `plans/grain-suite-temporal-response-r1.json` calibrates Add Noise CPU color, isolated Film Grunge grain, and Match Grain to the same initial green residual standard deviation. Over 128 frames, Add Noise is static, Film Grunge has per-pixel time autocorrelation lag1=.713/lag4=.022, and Match Grain is near zero at both lags with adjacent delta RMSE about 1.41× target RMS. This is synthetic-source-equation evidence only; actual playback perception and product routes remain unverified.

## Completion boundary

This research map does not establish aesthetic acceptance, physical film equivalence, GPU parity, runtime performance, or approval to integrate/change product effects. The film damage morphology models are not captures of the registered Composition effects. Each image comparison must first register its own evaluation plan under `docs/technical/IMAGE_EFFECT_RND_EVALUATION_RULES.md`. Builds, tests, application captures, or C++ execution require the applicable user authorization described in the repository guidance.
