## 1. 目的と対象

### 改善したい見た目

1 枚の画像（または合成テクスチャ）から、上下左右に継ぎ目なくタイリングできるテクスチャを生成する。生成結果は次の 2 点を同時に満たしたい。

- **継ぎ目が見えること:** タイリング（2×2 以上）した時、元画像の境界が境界線として見えない。
- **motif の重複を避けること:** 継ぎ目を消すために反転やコピーを繰り返した結果、同じモチーフが規則的に並んでいると不自然に見える。

この 2 点はトレードオフであり、どちらか一方の指標だけで判断しない。

### 対象素材・操作・経路

- **素材:** 決定論的に生成する合成 fixture 5 種 × 2 解像度（512×320 と 1536×1024）。実写写真は**未取得**。
- **操作:** オフラインの Python / NumPy / OpenCV による reference model。学習モデルは使わない。
- **経路:** 現時点では**オフライン fixture のみ**。Artifact の Composition、Render Queue、preview／final、GPU（D3D12 / Vulkan）は対象外とし、未検証として記録する。

### 対象外（未検証として明記）

- 実写写真での品質判定（ライセンス確認済みの素材が未取得）
- 学習型のテクスチャ合成（style transfer、diffusion 等）
- 製品の effect 登録、Inspector プロパティ、既定値、Undo、project 保存／再読込
- 実アプリの画像到達、CPU／GPU parity、backend 差、performance gate
- HDR 値域（1.0 超）と OCIO 色空間（現段階は SDR / sRGB のみ）

## 3. 評価素材

### 3.1 決定論的 fixture

seed `20261118`。生成手順・hash を `captures/rd0/fixtures_manifest.json` に保存する（`--check` で再検証できる）。

| fixture | 目的 | 失敗しやすい例 |
|---|---|---|
| checker | 硬いエッジ境界。feather による継ぎ目除去が効かない | 境界が直線的に残る、段差が残る |
| radial | 中心をずらした放射勾配。境界の連続性のみが滑らかな失敗例 | 色の段差が残る |
| clouds | multi-octave value noise。反復時に motif の重複が目立ちやすい | 同じ雲が規則的に並ぶ |
| blobs | ランダムな色块。境界をまたぐ低周波構造 | 円が切れて見える、境界に混入 |
| alpha_patch | 半透明 alpha 境界（straight / premultiplied 両版） | premultiplied / straight 契約の破綻、hidden RGB の漏えい |

alpha_patch の RGB は设计上ほぼ一様なので、**継ぎ目の視覚品質は評価対象外**（descriptor 契約の検証にのみ使う）。

### 3.2 実写素材

- **未取得**。GlowLab 等の CC0 資産の転用は、出所・ライセンス・SHA-256 の記録があるものに限る。実写での品質判定は取得まで未検証とする。

## 4. 画像条件

| 項目 | 固定／記録する条件 |
|---|---|
| 入力 | linear float（`ImageF32x4_RGBA` 相当）。straight と premultiplied の 2 条件を分離する |
| 設定 | 候補ごとに固定パラメータ。乱数源は manifest に記録 |
| 解像度 | 512×320 と 1536×1024 |
| 色空間・転送関数 | sRGB 8-bit と linear の 2 条件。表示変換は sRGB OETF 固定 |
| alpha | straight と premultiplied の両方を明示し、入出力契約をテストする |
| タイリング | 3×3 反復で継ぎ目を測る |
| 出力形式 | 目視用 PNG 8-bit と、測定用 float32 `.npy` |

## 5. 評価項目と合否

各項目に **評価領域／手順／判定者／合格条件／許容差／重大な欠陥** を定義する。数値閾値は baseline 取得後に設定するため、ここでは方法と期限を先に固定する。

### 5.0 閾値の確定手順（開始前の登録）

RD0 の baseline（素の反復）と候補の最終比較より**前に**、実装者とは別のレビュー者が §5.1〜5.6 の許容差と §5.7 の効果固有項目を数値で事前登録する。閾値未記入の項目は**未評価**とし、R&D 合格に含めない。評価後に閾値を変更する場合は理由・前後・承認者・影響する結果を残し、必要な比較をやり直す。

### 5.1 効果の正しさ

- **評価領域:** 全体、タイル境界線
- **手順:** 候補出力を 3×3 にタイリングし、境界をまたぐ輝度段差・RGB 段差・勾配エネルギーを baseline と同一条件で測る
- **判定者:** 実装者＋別レビュー者
- **合格条件:** 境界段差が baseline より明確に小さく、境界モードエネルギーが増えないこと。許容差は §5.0 で固定
- **重大な欠陥:** 境界が見える新的段差が出る、境界に带入・白線が出る

### 5.2 画質と細部

- **評価領域:** 全体、タイル境界線、テクスチャ特徴部
- **手順:** baseline / 各候補の 3×3 タイリングを同じ表示条件で blind review し、境界の視認性、テクスチャの連続性、motif の重複を記録する
- **判定者:** 別レビュー者（候補名を伏せた状態で判定）
- **合格条件:** 境界が視認できないこと、motif の重複が新規のものではないこと。許容差は §5.0 で固定
- **重大な欠陥:** 境界の段差、feather 帯の白線、極端なぼかしによる質感の消失

### 5.3 色と alpha

- **評価領域:** alpha 境界 fixture 全体
- **手順:** straight 入力と premultiplied 入力から復元した straight RGB の最大差、alpha の復元差、近透明領域の絶対値と >1 チャンネル数、非有限値数を測る
- **判定者:** 実装者
- **合格条件:** descriptor 差 0（float 丸めのみ）、近透明の >1 チャンネル数 0、非有限値 0
- **重大な欠陥:** descriptor 差が丸めを超える、近透明で発散、NaN / inf

### 5.4 時間安定性

- **適用:** 本ラボは静的なテクスチャ生成であり、時間変化は適用されない。**理由は記録する。** 連番画像での利用は未検討。

### 5.5 経路と解像度

- **評価領域:** 512×320 と 1536×1024
- **手順:** 同指標を 2 解像度で測り、傾向が一致するかを確認する
- **判定者:** 実装者
- **合格条件:** 方向性が一致すること。製品 preview／final、GPU backend 間は**未検証**

### 5.6 性能

- **評価領域:** 512×320 と 1536×1024 の 1 枚あたり
- **手順:** 実行時間（3 回の中央値）と tracemalloc peak を測る。Python heap のみである旨を明記
- **判定者:** 実装者
- **合格条件:** §5.0 で固定。**GPU 実装の予算ではない**

### 5.7 効果固有の項目

| 項目 | 測定 | 領域 | 備考 |
|---|---|---|---|
| 継ぎ目の視認性 | 境界をまたぐ輝度段差・RGB 段差・勾配エネルギー比 | 境界線 | 比は同一出力内の比較であり、低域化で内部エネルギーも落ちると比は 1 に近づく。段差の絶対値と併用する |
| 境界モードエネルギー | タイル境界周波数に占めるスペクトル比 | スペクトル | 完全周期ならほぼ 0 |
| motif の重複 | 8%〜50% ラグ帯の自己相関ピーク / 零ラグ | タイル全体 | mirror は反転で重複が出る |
| 質感の保存 | 低域化による局所コントラストの変化 | テクスチャ部 | periodic は継ぎ目を消す代わりに質感を弱める |

## 6. 画像統計による評価

- **画素値分布:** min / max / mean / 分位点、非有限値数
- **参照との差分:** baseline との輝度段差・勾配エネルギー比（参照は同一処理を通した baseline）
- **構造と細部:** 境界エネルギー、自己相関、局所コントラスト
- **色:** 境界をまたぐ RGB 段差
- **透明度・境界:** alpha 分布、descriptor 差、近透明の絶対値
- **ノイズ・時間:** 時間変化は適用しない（§5.4）
- **領域:** 全体、タイル境界線、テクスチャ特徴部。座標と画素数を記録
- 統計は目視レビューと組み合わせ、指標の改善だけで視覚品質の向上を断定しない

### 11.1 RD1 で記録された事実（記述的・判定を含まない）

- 素の反復の継ぎ目勾配エネルギー比は 10.3〜62.6（境界が内部より 10〜60 倍強い）
- periodic（トーラス低域化）は境界輝度段差を 0.205→0.036（clouds_small）のように大きく下げるが、局所コントラストも落ちる（質感の弱化）
- mirror は境界段差を約半分にするが、motif の反転による重複が避けられない
- **quilt 実装は継ぎ目を消せなかった**。半周期ずらした 2 枚を 1 本の縦 DP 経路で接合する単純実装では、2 次元オフセットの領域を分離できないため境界が残り、feather 帯の白線も出る（実装上の限界であり、手法全体の否定ではない）

### 11.2 判定していない事項

- 継ぎ目の視認性と motif 重複のどちらを優先するかは人手レビュー待ち
- 実写写真での確認は素材未取得のため未実施
- 正しい quilt（領域を囲む閉じた継ぎ目）の実装は未着手
