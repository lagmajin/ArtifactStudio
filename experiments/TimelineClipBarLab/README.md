# Timeline Clip Bar Lab

独立したブラウザー用テストプロジェクト。ArtifactStudio のプロジェクトデータを変更せず、タイムラインのクリップバー表現を並べて検討する。Diligent GPU描画を使うネイティブ版は `tools/TimelineClipBarPlayground/` にある。

## 起動

`index.html` をブラウザーで開く。ビルド、依存パッケージ、サーバーは不要。

## 試せること

- Current / Editorial / Compact の3案を同じサンプル時間軸で比較
- クリップ選択、ホバー、無効化、ズーム密度の切り替え
- 動画・画像・テキスト・音声・シェイプの内容と状態表示
- 境界ハンドル、音声波形、サムネイル風テクスチャ、再生ヘッドの視認性確認
- 選択したデザイン案を画面下部に記録

ネイティブ版はDiligent描画経路を確認するための別ターゲットで、ブラウザー版のクリック・ホバー機能は共有しない。

ここでのクリップは見た目検討用の固定データで、編集・保存・レンダリング機能は持たない。

## 評価計画

- **目的:** クリップの種類・選択状態・編集境界を少ない視覚ノイズで見分けられるバー表現を探す。
- **比較対象:** 既存の製品実装そのものではなく、`Current` は現行の視覚言語を要約した参照案。承認済みの正解画像ではない。`Editorial` と `Compact` は候補案。
- **素材:** HTML内に埋め込んだ架空のレイヤー名・色・波形・サムネイルパターン。外部素材なし。
- **条件:** ブラウザー表示、暗色の固定テーマ、通常密度・狭幅密度。色管理やOS間の厳密なピクセル比較は対象外。
- **評価:** 目視で種類判別、選択／hoverの区別、端ハンドルの発見性、ラベル可読性、狭幅時の破綻を記録する。画像品質統計はUIデザイン検討のため対象外。
- **実行条件:** 依存なしのHTML/CSS/JavaScript。GPU／レンダラー性能や実アプリ経路は未評価。

## 制約

現行の `ArtifactTimelineTrackPainterView` にある実際の hit-test、トリム、選択同期、テーマ、字幕・波形・動画サムネイルの各処理との一致は未検証。採用案を製品へ反映するには、別途レビューと実アプリでの確認が必要。
