# 学習モデルの入手と記録

**最終更新:** 2026-11-15
**Status:** 未入手（rd1 開始時に確定する）

このラボはモデルの重みをリポジトリに含めません。`models/` は `.gitignore` 済みで、以下を記録してから使用します。

- 出所 URL
- ライセンス（コードと重みで異なる場合は両方）
- ファイル名、サイズ、SHA-256
- 前提とする入力契約（NCHW / NHWC、0〜1 正規化、期待倍率、alpha 非対応の有無）
- 入手日と入手手段（直接ダウンロード、変換スクリプト、再配布パッケージ）

記録先は本ファイルと、実行時の `captures/<rd>/manifest.json`（重み hash を duplication して保持）。

## 候補

| 候補 | 期待倍率 | 用途 | 備考 |
|---|---|---|---|
| Real-ESRGAN x4plus | ×4 | 一般写真の基準候補 | 代表的な汎用超解像。計算コストは大きめ |
| RealESRGAN x2plus | ×2 | ×2 の基準候補 | ×2 専用。x4 を縮小して代用しない |
| realesr-animevideov3 | ×4 | アニメ・線画系 | 実写写真には不向きな可能性。用途別に分けて評価 |
| EDSR / ESPCN 系（軽量） | ×2 / ×4 | 「小さいモデルで足りるか」の対照 | ライセンスと ONNX 入手可否を要確認 |

いずれも「入手できる ONNX が前提」であり、PyTorch 重みからの変換が必要な場合は変換手順・変換元バージョン・変換後 hash を記録します。変換の有無で結果が変わるため、変換物は一次証跡として区別します。

## ライセンス確認の方針

- コードと重みのライセンスを分けて確認する（同一リポジトリでも別条件のことがある）。
- 再配布が制限される重みは、ローカル配置のみで運用し、リポジトリや成果物に含めない。
- 商用利用可否は本ラボでは判断せず、未確認として残す。判断が必要になった時点で別途確認する。

## 未確認事項

- 上記候補の ONNX 形式での入手可否と、入手元ごとの数値一致
- ×2 専用モデルと ×4 モデルの縮小利用を混在させた場合の比較妥当性
- 8-bit sRGB 前提のモデルを製品の linear 経路へ載せる場合の色空間契約（本ラボの対象外）
