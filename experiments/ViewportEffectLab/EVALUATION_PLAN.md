# Viewport Effect Lab 評価計画

**最終更新:** 2026-11-24

ブラー強度と不透明度を同じ数値 Gizmo で操作する。独立試作はこのディレクトリをローカル HTTP で配信し、index.html を開く。素材はコード生成の細線、硬い縁、点光源、半透明図形。640×360、sRGB SDR、固定フレームで、ブラーは Canvas の固定半径 12 px。元画像とブラー結果を強度で補間する。

操作テストは `node --test experiments/ViewportEffectLab/interaction.test.mjs`。2026-11-24 に3件通過。ドラッグと数値入力、ポインターの所有権とキャンセル、別パラメータへの再利用を確認した。ブラウザの実際の入力配送と画素は未確認。

製品では、ブラーを適用したレイヤーの VP 詳細メニューから強度または半径を選び、表示されたハンドルをドラッグする。Esc、フォーカス喪失、ハンドル外クリック、修飾キー、開始位置に戻した操作を確認する。確定1回につき Undo 1件で開始値に戻り、Redo で確定値に戻ることを確認する。

画像比較の基準は、同じシーンの同じエフェクトをインスペクターで設定した値。0、低、中、上限、往復中の同じ値について、固定フレームの RGBA 最大差、MAE、分位点、エッジ幅を全画面と細線・点光源・半透明境界で比較する。同じ解像度とバックエンドで画像が一致することを合格条件とする。黒・白背景で縁を目視し、HDR と半透明の値、固定値の連続フレームの差も記録する。プレビューと最終出力で解像度、色空間、転送関数、露出、alpha 形式、GPU、フレーム、ファイルハッシュを記録する。

D3D12 と Vulkan の 1080p 操作中に、フレーム時間 p95 と GPU メモリを測る。既存経路の計測後、最終比較前に許容差を決める。製品のビルド、画像、性能、Undo の評価はいずれも未実施。
