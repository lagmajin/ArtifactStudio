# Sequence Gap Acceptance Project

**最終更新:** 2026-11-19

## 用途

PNG連番のファイル列認識、欠番時の扱い、シーク位置、書き出しフレーム番号を確認する手動受入プロジェクト。素材は同階層の `assets/` にあり、`frame_0004.png` だけを意図的に欠番にしている。

## 作成するプロジェクト

- Composition: 96×96、24 fps、frame 1–6
- Image Sequence layer: `assets/frame_0001.png` から連番として読み込む。欠番を埋めず、番号順を維持する
- 保存名: `SequenceGapAcceptance.artifact`
- Source path: project-relative asset path

素材の格子模様は画面位置を示し、赤い四角は各フレームで右へ移動する。左上の色マーカーは画像の識別用。

## 確認手順

1. 1、2、3、5、6番をシークし、位置が順に進むことを記録する。
2. 3番から4番へ移動し、欠番のフォールバックが表示されることを確認する。続けて5番を表示し、番号と画がずれていないことを確認する。
3. 保存して閉じ、プロジェクトと `assets/` を別フォルダへ移動する。元の場所から読めない状態で開き、1・5・6番が表示され、4番が欠番のままであることを確認する。
4. 別のフォルダへ素材をコピーし、`relinked_0001.png` から `relinked_0006.png` の命名に変える。4番だけは `frame_0006.png` のコピーを `relinked_0004.png` として置く。移設先の `assets/` を一時的にリネームしてから、Project View の連番素材を `relinked_0001.png` へ再リンクする。
5. 4番で6番のマーカーが表示され、3・5・6番にはそれぞれ元のマーカーが表示されることを確認する。保存して開き直し、同じフレームを再確認する。
6. 再リンク後の4・5番を Preview と Render Queue から無損失 PNG で取得する。96×96、色空間・表示変換・フレーム番号をそろえ、各フレームで RGB のいずれかの差が8ビット値で2を超えるピクセルが0.1%以内か確認する。4番の書き出しが手順4の置換画像と対応することも確認する。

## 素材の再生成

`python generate_sequence.py` を実行すると同じ5枚を生成する。これはプロジェクト素材生成であり、ビルドやテストは起動しない。
