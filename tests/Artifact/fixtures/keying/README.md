# Keying test fixture

`voa-green-screen-frame-2s.jpg` is a test-only frame derived from VOA Learning
English's [“Filming with the green screen”](https://commons.wikimedia.org/wiki/File:Filming_with_the_green_screen.webm)
video. The frame was extracted at 2 seconds and resized to 540 × 960 pixels;
the image is otherwise unaltered. It is used to exercise Chroma Key on a real
studio setup with a green backing, a presenter, and a non-green background.

The Commons file page lists the source as a 1,080 × 1,920, 14.268-second video
published on 2023-07-07. The original frame-extraction tool/version was not
recorded; the stored fixture is pinned by the SHA-256 below. It can be replaced
with a reproducibly extracted frame if exact frame-decoding reproducibility is
needed.

The Commons file page identifies the video as public domain because it was
created and provided by Voice of America. VOA's [copyright terms](https://www.voanews.com/p/5338.html)
state that material produced exclusively by VOA is public domain. Attribution
is included here for provenance: **VOA Learning English, “Filming with the
green screen” (2023-07-07)**. The Commons page also marks the license as needing
review. VOA's terms exclude third-party licensed content, so the Public Domain
basis relies on the page's attribution of this video to VOA Learning English;
the license-review marker is retained here as a provenance caveat.
