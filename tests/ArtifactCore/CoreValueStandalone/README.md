# ArtifactCore Core Value Standalone Tests

This project registers the Optional, String, Array, Expected, and DiskSize
contract suites. They reuse the common Core, Container, and SharedPtr module
target in the combined standalone suite.

Configure this directory for focused work, or use
`tests/ArtifactCore/StandaloneSuite` to share the same foundation module
artifacts with CoreUtility, Color, FrameRate, Geometry, RawImage, Data, Audio,
Asset, DiagnosticEngine, and OpenEXR suites.
