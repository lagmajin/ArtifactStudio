# Layer Transition Playground

フェードイン／フェードアウトとブラーを組み合わせるレイヤー用トランジション設定画面の、独立したブラウザー試作です。

## 起動

`index.html` をブラウザーで開きます。ビルド、依存パッケージ、ArtifactStudio本体は必要ありません。

## 試せる内容

- フェードイン／アウトの有効化、長さ、イージング
- ブラーの有効化、最大量、フェードとの同期
- プリセット選択とカスタム設定への切り替え
- 選択レイヤーへの適用対象表示
- パラメーター変更に連動するタイムラインカーブのプレビュー

この試作は操作感と設定項目を検討するためのUIです。ArtifactStudioのレイヤーデータ、キーフレーム、Undo、レンダリングには接続していません。
